# Control Your Video

从聊天里的想法和素材出发，一起做完整视频。助手负责理解和组织制作，创意方向、完整方案、小样和最终效果由你判断。

插件版本 0.5.0。这一页说明它怎么工作、边界在哪；安装与最短上手路径见 [README](../README.zh.md)。

## 开始创作

新开 DSH 会话并选择 **视频创作**。给助手一个想法、脚本、当前项目素材或明确的修改请求。

完整视频依次经过三个确认点：

1. **创意方向**。助手提出少量真正有区别的方向并说明推荐，你用 `cyv` 的 `creative` 确认。
2. **完整方案**。全片逐镜写进 `plan.md`，先过 `plan-check`，再批准这个版本（`approve_plan`）。
3. **代表性小样**。按批准的制作清单渲染真实小样，你观看后认可（`approve_sample`），才允许全片。

每次认可都记在宿主里并绑定内容版本：方案认可记 `plan.md` 摘要、制作清单与小样镜头选择，小样认可记样片 SHA-256。脚本改了方案或换了版本，之前的认可不再算数。

修改会另存完整新版并保留旧版。只处理现有片段的字幕任务有独立入口 `subtitle_edit`，不必走三个确认点，也不需要先有创意方向。

项目放在工作区里的普通文件夹。当前作品的用户素材复制到项目内并保留原件。仅在你选择后，已交付作品的经验或资产才按使用场景复制入本地库。

## 三个确认点能保证什么

- 保证：在 `cyv` 内置路线上，助手继续制作时依据的是你确实批准过的那个内容版本；改项目里的文字状态拿不到制作权限。
- 不保证：技术上无法绕过。预设挂的是标准工具清单，Shell 与文件写入都在，本机渲染可以不经 `cyv` 直接驱动。这套确认是流程约束，不是运行时硬门禁。详见[工程验收](工程验收.md)。

## 可用制作方式

当前受控制作适配器使用本机 FFmpeg 和 FFprobe：程序画面（四种生成图案）、项目内照片、既有视频三种画面来源，可叠字幕；音频支持无声、程序音调、自带音轨与沿用镜头原声。具体能力以 `cyv` 的 `local_capabilities` 实测为准——它报的是本机真能找到的版本与编码器。

FFmpeg 是随包的一条制作路线，不是唯一路线。助手也可用本机代码、图形或剪辑工具出片：通过 `approve_plan` 的 `external` 参数固定路线和关键输入，用 `prepare_run` 准备小样、全片或修订阶段，再用 `register_artifact` 完整解码并登记实际 MP4。直接使用 Shell 绕过 `cyv` 的独立制作不受这套流程约束。

生成模型可选。宿主插件可以提供 `controlYourVideoMediaProviders` 服务。项目授权分别绑定具体模型、用途、提示词传输范围和累计预算；同一范围内可自主安排调用与重试，相同操作重放不重复占用费用。费用或交付结果不明时会保留占用并停止继续派发。本仓库只用模拟提供方验证，尚未连接真实计费服务。

专业 Skill 按任务加载。公开资料核对可以交给另一个独立预设：它挂网页检索与读取、文件查看、待办与提问，负责查证公开来源，创意与制作仍归主会话。

## 经验库

位置是 `<工作区>/control-your-video/`。你不主动要用，它不会被创建，也不会铺占位文件。条目按使用场景归类，读与写都要你明确同意，收录发生在交付之后。

## 验证到哪为止

- 本版 `npm test` 复测 **104/104 通过**；19 个脚本语法检查通过，预设 28 项挂载成功，另 2 项按平台或配置禁用。
- 隔离宿主冒烟通过真实 DSH 执行器、用户问答、JSON 存储与 FFmpeg，覆盖内置及外部本地路线的小样、全片、完整修订、独立字幕、经验库和模拟模型授权。存储另重开两次，预算与阻断状态可恢复。
- 已验证环境为 Windows 11、DSH Desktop `0.2.2-rc.5`、Node 24.22.1、FFmpeg/FFprobe 9.0.1。其他平台未测。
- 用户在 `0.4.0-rc.3` 上完成真实最小正片并反馈核心 Skill 达到预期。这是用户陈述，不是本版的留存测量记录；具体片名、技术路线与时长不在本仓库里。
- 没有 A/B 对照、多题材或多人使用验证，也没有跨第二支片的库复用验证。真实模型服务、实际计费、本版 Desktop 手动安装与完整作品体验仍待验收。
