# 可选媒体提供方

主 Agent 可按作品需要选择本机制作路线。媒体提供方属于可选的宿主集成，需要获得具体服务使用授权后再配置和验证。

一个受信任的宿主插件可提供 `controlYourVideoMediaProviders` 服务值，包含经安装者配置的提供方列表。每个提供方声明 `id` 和 `models`，型号条目提供 `{ id, capabilities }`。模型清单应描述当前部署真实可用的模型与能力，不读取或返回密钥。

每个提供方实现两个异步操作：

- `estimate(request, { signal })` 返回所用货币的最小单位数，例如人民币分。采用可信定价、无法估算则拒绝，估算时不得开始生成。
- `generate(request, { signal, maxCost })` 执行已明确批准的一次调用。由适配器落实预算与取消，返回 `{ mime, bytes }`，其中 `bytes` 为 `Uint8Array`。当前宿主接受 PNG、JPEG、WAV 和 MP4，保存到本项目的素材目录。

`request` 含操作 ID、提供方与型号、授权上限、货币与发送给服务的提示词。现有独立素材入口仍支持单次选型及费用确认。

项目复用同一授权时，先调用 `cyv approve_media`，提供 `project`、`provider`、`model`、`purpose`、`currency` 和累计 `costLimit`。宿主分别确认选型与该用途的文本传输范围，以及费用上限。`generate_one_asset` 传返回的 `grantId`、该请求唯一且稳定的 `operationId`、相同的提供方、型号、用途、币种与提示词文本。每项新请求使用新的任务标识。相同任务标识仅查询或返回原结果，费用不重复占用。

同项目、同模型、同用途和预算范围内调用次数由 Agent 自主安排。每次派发前检查预算余量并为估价保留金额，由提供方落实本笔上限。费用或交付结果不明时停住并报告，等核实实际状态后再确定后续授权。更换模型、改变用途或要扩大传输和付费范围时重新确认。接口只承载提示词文本。敏感内容的用途与传输边界需要在发送前核对，宿主未对任意文本自动作敏感性判断。

当前验证使用隔离宿主和模拟提供方，未连接真实计费服务。
