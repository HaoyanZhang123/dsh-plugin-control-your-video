# 可选媒体提供方

当前候选版的非生成路线只依赖本机 FFmpeg。媒体提供方属于可选的宿主集成，需要选择具体服务后才配置和验证。

一个受信任的宿主插件可提供 `controlYourVideoMediaProviders` 服务值，包含经安装者配置的提供方列表。每个提供方声明 `id` 和 `models`，型号条目提供 `{ id, capabilities }`。模型清单应描述当前部署真实可用的模型与能力，不读取或返回密钥。

每个提供方实现两个异步操作：

- `estimate(request, { signal })` 返回所用货币的最小单位数，例如人民币分。采用可信定价、无法估算则拒绝，估算时不得开始生成。
- `generate(request, { signal, maxCost })` 执行已明确批准的一次调用。由适配器落实预算与取消，返回 `{ mime, bytes }`，其中 `bytes` 为 `Uint8Array`。当前宿主接受 PNG、JPEG、WAV 和 MP4，保存到本项目的素材目录。

`request` 含单次操作 ID、提供方与型号、授权上限、货币与发送给服务的提示词。宿主先向用户展示具体模型及传输的提示词，再单独询问费用。示例代码和测试不连接真实服务。一次操作授权不得复用。批量调用及同模型重试语义保持开放，等用户决定。
