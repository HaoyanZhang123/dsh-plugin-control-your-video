## 一、可迁移的写法

基础结构（散文式，四段）：

```text
<散文场景：谁、在哪、什么天气与服装，用具体名词>
Cinematography: Camera shot: <景别与角度>; Mood: <整体调性>
Actions:
- <节拍 1：具体动作或手势>
- <节拍 2>
Dialogue: <短句，控制在几条之内>
```

进阶版再加：格式与质感、镜头与滤镜、调色与色板、光线与氛围、地点与构图、服装道具、声音、分镜表（带时间）、镜头说明、后期。

四条判断：

1. **一个镜头一个机位一个动作**。多镜头可以写，但要按镜头分块，每块只给自己那一套机位、动作、光线。
2. **动作写成节拍**。“走过房间”改成“走四步到窗前，停一下，最后一秒拉上窗帘”。
3. **具体名词胜过形容词**。文档的三组强弱对照值得直接记：
   - “夜晚的漂亮街道” → “湿沥青、斑马线、霓虹倒映在水洼里”
   - “人快速移动” → “骑车人蹬三下、捏闸、停在斑马线前”
   - “电影感” → “变形宽银幕 2.0x 镜头、浅景深、体积光”
4. **留白是双向的**。写细 = 可控但可能僵；写少 = 有惊喜但不可控。要一致性与连续性就写细，要探索就留白——先问这次要哪一种。

## 二、声音与对白

- 对白放在独立的 `<dialogue>` 块里，与画面描述分开；长篇独白对不上时长，短句更容易对上。
- 多角色场景给每句标清说话人，并交替。
- 静默镜头也可以给一个小声音当节奏提示（远处的车流、一声脆响），不必配整条音轨。

## 三、编辑与延长（写法可借，接口已过期）

- 编辑按“一次改一件事”写，并说清改的是什么（“同机位，换 85mm”“同样光线，色板换成青、沙、锈”）。
- 结果已经接近时，把它当参考钉住，只写那一点改动，其余保持。
- 反复失败就**减复杂度**：固定机位、简化动作、清空背景，先让它成立，再一层层加。
- 历史上的延长规则：用完整原片当上下文，单次延长有上限，且有累计次数上限。**具体数值已随接口关停失效，不要照抄**。
