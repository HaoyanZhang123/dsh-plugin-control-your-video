# MiniMax H3／H3 Max：两代差异、时长整数与参考素材上限

> 何时读：已选定 MiniMax H3 或 H3 Max，要确认时长能不能写小数、参考素材能放几份、首尾帧怎么表达时。读它是为了在上传前就砍掉会被接口拒收的组合，并知道这两个型号各自缺什么能力。

## 版本与状态

- 来源 URL：https://platform.minimax.io/docs/guides/video-generation （MiniMax 官方；示例集另见 https://platform.minimax.io/docs/guides/video-prompt ）
- 页面自述版本：MiniMax-H3 / MiniMax-H3-Max，抓取时在线版本（无发布日期、无下线说明）
- 抓取日期：2026-10-29
- 许可：unknown（D 级或未定），仅作方法研究，不随包
- 是否实测：**否**。以下全部是文档声明，本机未调用接口、未生成任何片段。

## 一、两个型号不是同一档

| 项目 | MiniMax-H3 | MiniMax-H3 Max |
|---|---|---|
| 定位 | 通用多模态视频模型，支持生成、参考创作、视频编辑 | MiniMax 与 fal.ai 联合发布，在 H3 上后训练的高速版 |
| 输出分辨率 | 768P / 2K | 480P / 768P |
| 输出时长 | **4—15 秒，只能整数** | **5—15 秒，只能整数** |
| 模式 | 文生、图生、参考生 | 文生、图生、参考生 |
| 文档里的示例代码 | 有（四种模式） | **没有** |

两条直接结论：

1. 用户说“3.5 秒”“4.5 秒”，**这个型号写不了**。要么改整数时长，要么把 0.5 秒交给剪辑补；不要写小数去试。
2. H3 Max 起步就是 5 秒，且只有 480P/768P。要 2K 或要 3—4 秒，只能用 H3。

## 二、比例：三种模式三种规则

- 文生视频：`ratio` 必填，**不能 adaptive**。
- 图生视频：比例由输入图决定，`ratio` 恒为 adaptive。
- 首尾帧：同上，跟着图走。
- 文档对可用比例的表述是“常见比例，或 adaptive”，逐项清单在 API 参考里（本库未收）。

所以：**想指定画幅就得走文生视频**；给了图，画幅就不是提示词能决定的事。

## 三、输入：数量与硬上限

| 项 | 文档声明 |
|---|---|
| 首帧／尾帧 | 0、1 或 2 张；宽高 256—5760；宽高比 2:5—5:2；无图即降为文生 |
| 参考图 | ≤9 张，尺寸同上 |
| 参考视频 | ≤3 段，每段 2—15 秒，合计 ≤15 秒 |
| 参考音频 | ≤3 段，每段 2—15 秒，合计 ≤15 秒 |
| 混合输入 | 合计 ≤12 个文件 |
| 格式 | 视频 H.264/H.265（含音轨 AAC/MP3）；图 JPG/PNG/WEBP/HEIC/HEIF；音频 WAV/MP3 |
| 单件体积 | 视频 ≤50 MB、图 ≤30 MB、音频 ≤15 MB（按单件，不按合计） |
| 请求体 | ≤64 MB；大素材建议传 URL |
| 提示词 | ≤7000 字符 |

超过数量时的判断顺序：先砍“只做风格参考”的图，再砍重复视角的主体图，最后才动声音参考。合计数超标时优先用视频代替“多张连续图”。

## 四、角色靠字段表达，不靠参数名

参考素材的用途写在 `content[]` 的 `role` 上：`first_frame`、`last_frame`、`reference_image`、`reference_video`、`base_video`。

- **没有** `subject_reference` 这类参数。想做“主体参考”，就是传 `reference_image` 并在正文里说清它管什么。
- 2K 重生成（Regeneration）要把原请求的 `content` 全量复现一遍，再加一个 `role=base_video` 的源视频；少一项就不成立。
- H3-Context-IR 只返回增强后的提示词，不出片。把它当“帮我把提示词写全”的工具，不当生成。

## 五、提示词写法（从示例集反推）

示例的公共顺序：

```text
<时长>, <画幅>. <风格或片型>.
Image 1: <这份参考管什么>. Image 2: <管什么>.
Story: <谁、在哪、发生什么、转折>.
<景别与运镜要求：中近景/特写用于眼神与张力>.
Sound: <环境声或情绪要求>.
```

- 先给画幅与时长，再给参考职责，再讲故事，最后给镜头与声音。
- 参考职责一句话一份（mood／character／product／logo），不写“参考所有图”。
- 示例集只有 6 条成品（品牌片、视觉创意、AI 叙事、产品电商、数字体验、动画风格，各一条），没有公式与关键词表；不要把某一条示例当模板套所有题材。

## 六、明确没有的东西

- **没有帧率**；**没有“原生音频生成”的声明**（音频只作为参考输入出现）。要声音就走 `video-craft` 的声音部分，别假定这个型号会出声。
- **没有多镜头、没有延长**。要分镜或续接得走别的模型或剪辑。
- 没有逐字段 required 表，只有代码示例；H3 Max 连示例都没有。
