## 一、先判 locked 还是 unlocked

这是本型号最该先看的一张表：输入素材会不会把输出的比例甚至时长钉死。

| 任务 | 类型 | 被锁什么 | 参数侧要求（文档） |
|---|---|---|---|
| 编辑（改画面／改音频） | locked | 比例对齐原片，**时长也锁** | `ratio=adaptive`，`duration=-1` |
| 延长（向前／向后） | locked | 比例对齐原片，时长用户定 | `ratio=adaptive` |
| 首帧／首尾帧 | locked | 比例严格对齐首帧；首尾帧画幅不一致时尾帧会被拉伸 | `ratio=adaptive` |
| 参考（主体／风格／动作／声音） | unlocked | 不锁 | 比例与时长可指定 |
| 多宫格分镜 | unlocked | 不锁 | 比例与时长可指定 |
| 关键帧 | unlocked | 不锁 | 比例与时长可指定 |

两条推论：

1. 用户要“改一句台词但保持横屏”，如果原片是竖屏，**参数层面无解**——编辑锁比例。要么接受原比例，要么换参考模式重生成（内容会变）。
2. 首尾帧用 `first_frame`/`last_frame` 会锁比例；改用 `reference_image` 并在正文里指定首尾帧则不锁比例，但只“相似”，不严格对齐。要严格对齐就接受锁比例。

另外：编辑与延长的参考视频须为 4—30 秒；一个请求最多 50 个参考素材（图／视频／音频合计），其中图 ≤30（分辨率至 4K）、视频 ≤10 且合计 ≤30 秒、音频 ≤10 且合计 ≤30 秒；单条成片最长 30 秒。

## 二、提示词的四段结构

1. **素材指代**：按上传顺序编号（Image 1 / Video 1 / Audio 1），逐份写用途。
2. **一句话概述**：主体 + 地点 + 事件 + 题材／风格 + 特殊运镜。
3. **具体情节**：用时间戳或 `Shot N` 切段，逐段写画面、运镜、动作、台词、声音。
4. **补充说明**：贯穿全片的机位、环境、氛围、声音要求。

素材够准时**只指代、不复述**（“严格参考视频 1 的动作与运镜，顺序一致”），复述细节反而会被改掉。不要只在图片上写名字再在正文里喊名字；多主体要逐条列映射。

## 三、时间戳

- 以 **1 秒**为基本单位；2.5 认整数秒时间戳，2.0 只认镜头序号（同一厂商两代规则不同，按型号查）。
- 三种控制：时间区间（`0s-5s`，必须连续，别跳段）、时间点（“第 5 秒快速向左横移转场”）、相对时间（“3 秒后周围的人开始摇头”）。
- 段内剧情太少 → 模型自由发挥；太多 → 过度剪切或漏情节。这是“切点不听话”的最常见原因。
- 不建议用时间戳控高频动作（“一秒摇头三次”），控制不了。

## 四、音频标记与声音写法

| 标记 | 含义 | 例子 |
|---|---|---|
| `{}` | 对白 | `Lina says: {It's showing us the way.}` |
| `<>` | 音效 | `<footsteps on gravel>` |
| `()` | 音乐 | `(upbeat instrumental, outdoor sports feel)` |
| `(V.O.)` | 画外音 | `Qin Xiulian (V.O.) says: {…}` |

- 声音可细分到对白／音效／BGM 三层分别否定。
- 文档承认：**“不要 BGM”仍可能被绕过**。可查的做法是把音乐相关同义词穷举（music、BGM、score、instrumental、melody、synth、pad…），并在开头与结尾各写一遍；剩下的靠后期去掉非人声音轨（会连音效一起没）。
- 对白后重复台词、或给每句台词单独加语气／表情说明，容易触发字幕生成。要分句给表演，用分句格式，不重复台词。

## 五、已知会翻车的地方（文档自己写的）

| 现象 | 文档给的成因／处理 |
|---|---|
| 成片比原片短约 0.33 秒 | 编辑帧数机制所致；要精确时长就换参考模式，或把输入调整到 8n+1 帧 |
| 多主体角色与参考对错位 | 按首次出场顺序上传，并同步改正文编号 |
| 屏上字拼错 | 把词拆成字母逐字出现，或把正确文字做成图当参考 |
| 参考视频带字幕，输出也带字幕 | 换一条无字幕的参考视频 |
| 参考图分辨率过高长出指纹状纹理 | 把图缩到不超过输出分辨率 |
| 一个任务里混了参考＋编辑＋延长 | 拆成两次任务，各自验收 |
| 强烈情绪词让瞳孔发光 | 改成中性情绪描述，并明确“眼睛正常、不发光” |

## 六、分镜素材

- 多宫格分镜建议 ≤15 格；18 格这类容易出现静止帧或顺序错乱。
- 用线条／火柴人分镜，别用过锐化、字很多的 AI 直出分镜。
- 分镜图**不会被逐格严格执行**；要严格对齐就用关键帧参考，并在首句写明“这是关键帧参考”。
