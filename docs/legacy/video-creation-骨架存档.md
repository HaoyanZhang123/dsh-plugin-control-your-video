# 视频创作

## 1. 先判断这次是什么任务

放：识别用户给的是感觉、文案、素材、已有成片还是修改意见；哪些是明确要求、哪些需要自己补；什么情况下不必重做整体方案。

## 2. 承接与补全

放：已有内容怎么接住不覆盖；什么时候直接推进、什么时候只问一个真正改变结果的问题；不把翻译工作推回给用户，也不假装已经理解了没表达清楚的部分。

## 3. 作品形态与体验判断

放：论述、情绪、清单、教程、宣导等不同形态分别该检查什么；同一套方法为什么不能套到所有片上。

## 4. 整体方案

放：核心表达、观众体验、内容推进、节拍、视觉与声音方向、制作路径。给可感知的选择与理由，不是形容词堆叠。

## 5. 镜头、小样与制作路径

放：怎样把方案落到能做的镜头；每镜要交代什么；代表小样该验证哪几个风险、多长、和成片用什么关系；怎么按当前可用工具选做法。

## 6. 制作组织、检查与修改

放：真的要动手时怎么排顺序、怎么调用工具、缺工具怎么办；改完检查什么；反馈到手先判断保留、局部修补还是要重做；哪些结论必须由用户看/听才能下。

## 边界

放：不做逐阶段审批；不替用户宣布认可；不承诺没验证过的模型或工具能力；不用抽帧冒充连续观看；不建版本系统。
