## 0. 判定标尺

### 0.1 四档（"能直接改善画面吗"）

| 档 | 含义 | 判据 |
|---|---|---|
| **S** | 立刻可用 | 把它喂给模型（检索/注入提示词）当天就能改善成片；不需要改引擎结构 |
| **A** | 需先扩引擎槽位 | 内容本身可用，但缺一个引擎能力承载它，槽位不到位就是死文件 |
| **B** | 只在解冻生成式后才可用 | 内容是"怎么让外部模型生成"，冻结生成式的第一版里没有落点 |
| **C** | 当前无用 | 法务、产品参考、与画面无关，或薄到无内容 |

### 0.2 十个槽位（A 档必须点名）

镜头运动 / 分层混合 / 遮罩 / 排版 / 时间重映射 / 音频驱动 / 风格系统 / 字幕时间线 / 质感调色 / 图形图解。

### 0.3 三种形态

| 形态 | 含义 | 权利要求 |
|---|---|---|
| **知识库** | 包外，模型检索读；文档不随包分发 | 可收任何可读材料，但**不能把原文搬进仓库** |
| **代码** | 提炼成引擎能力，重实现 | 只有 MIT/本仓库自写可直接改；Apache 需留 NOTICE；**AGPL 与修改版 Apache 只能 clean-room 重写** |
| **资产** | 模板/预设/数据文件，随包分发 | **必须有明确可再分发的权利依据**，否则只能留作包外参考 |

> 许可分级的依据不是我推的：`08-许可标准与质量\07-已确认资产边界核对\边界核对.md` 已把全库分为 **A 纯自写/MIT、B 会引入 Apache 义务、C 只能学思路、D 权利不明** 四级，并点名 **AGPL 4 处**（`01-04`、`04-07`、`05-03/02-实现/openmontage-audio_mixer`、`05-04/02-OpenMontage-TTS`）、**PolyForm 非商业 1 处**（`02-02`）、**hypit 修改版 Apache 3 处**（`02-06/07/14`）、**权利不明字体 67 个**（`01-05`）。本报告形态列直接沿用该分级。

### 0.4 证据强度标注

`全文` = 读过代表文件正文；`说明` = 只读了目录自带说明与其列举；`推定` = 仅凭目录名、扩展名分布与同类目录推定，**未打开内容**。表格最后一列标注。
