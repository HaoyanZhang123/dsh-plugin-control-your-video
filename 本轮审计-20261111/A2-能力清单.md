# A2 · 这个插件目前做到了什么

> 对象：`产品实现\`（生产代码 53,783 行；测试 15,973 行 / 62 个 `.test.mjs`，实测）。Lead 已确认的事实直接引用。

## 0. 三句话

1. **能跑的是本地项目数据库 + 只读观察台**：建项目、传材料、写用途、存偏好、存"回到上次位置"真的写盘。
2. **画面能力为零**：渲染/编辑/编排/交付从 `ui/plugin/host.js` 不可达（可达 21,630 行、不可达 35,035 行），装上后一行不执行。
3. 它现在是**一套被验收过的基础设施 + 一批人肉脚本**，不是产品（第四节）。

## 三、防御性代码占比

按文件名归类统计：

| 类别 | 构成 | 行数 | 占比 |
| --- | --- | --- | --- |
| 防御性 | `base\` 10 文件 + `core\project\` 的 versions/recovery/store/write-guard/production-lock/migrations/schema | **6,685** | **12.4%** |
| 创作性 | `media\`（除 `render\` 与 fixtures）+ `craft.js` + `direction.js` | **5,611** | **10.4%** |
| 界面 | `ui\` + `delivery\` | **14,978** | **27.8%** |
| 工具管理 | `tools\` | **7,422** | **13.8%** |
| 其余 | core 业务 5,536 + `editing` 5,389 + 编排非创作 4,573 + `media\render` 2,943 + fixtures 646 | 19,087 | 35.5% |

校验：6,685+5,611+14,978+7,422+19,087 = 53,783，与总数一致。

**说明什么？**

1. **87% 的代码不产生画面**：防御 + 界面 + 工具 + 记录/校验 = 89.6%，扣掉暂不可达的编辑逻辑仍过八成。
2. **创作能力只有 10.4%，核心仅 1,176 行**（`craft.js` 327 + `direction.js` 849）——这是全部的"怎么拍才好看"；`media` 4,435 行多是探测、重映射、音画对齐、校验，也是约束而非表达。
3. **比例没错，顺序错了**：地基和门禁做到满分，创作那 10.4% 连执行入口都没有；6,685 行防御换来"不丢数据"，用户打开看到的第一个画面却是"尚无合成画面"（`work.js:71`）。

## 四、Q5 判定

**这个插件是"一套被验收过的基础设施 + 一批人肉脚本"，不是"一个产品"。**

1. **产品里没有创作驱动。** `acceptance\mixed-project\scripts\` 21 个 `.mjs`（全 acceptance 52 个）承担全部"从想法到片"；`render.mjs:7` 直接 `import { createMediaRuntime, probeMedia, resolveToolchain } from '../../../media/index.js'`，`build-plan.mjs:6` 直接调 `normalizePlan`/`deriveLayout`——产品库是被脚本调用的库。
2. **`build-plan.mjs` 28,702 字节，是手写 CompositionPlan 的脚本**（自述"Build the C16 mixed film's CompositionPlan(s)… One builder, several variants"）——"这一版长什么样"由人写 JS 决定，不经界面。
3. **对外只有 19 条 UI 数据接口**（`routes.js:84-107`），没有一条涉及渲染、编辑会话、交付执行；`ctx.tools`/`defineTool` 全树 0 命中，它连"给 agent 用的工具"都不是。
4. **62 个测试里 42 个测基础设施**，20 个测的是不可达代码；`product-journeys` 也没让画面动一下。

边界说清：基础设施（C10 项目内核 + C06 工具内核 + 只读 UI）是产品级的；"做出片子"还不是产品的一部分。

## 五、按影响排序：离"能做出让人满意的片子"还差什么

| # | 差距 | 依据 |
| --- | --- | --- |
| 1 | **渲染触发入口**：把 `media\render` 2,943 行接进路由，让"设入点→出片"能点。 | `work.js:89`；`routes.js` 无渲染路由；render 仅被验收脚本调用 |

| 4 | **让 AI 真的看画面**：现在永远显示"未看/未听"，没人替用户判断好不好。 | `creation/view.js:157-163`、`realwork/view.js:131-138` |
| 5 | **审阅从"读"变"改"**：接受/退回/重渲按钮不存在，看到候选也推不动。 | `review/view.js:261`、`project.js:240` |
