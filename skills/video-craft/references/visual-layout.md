# 版式通则

> 何时读：画面太空、太挤、元素都在抢注意力，或要判断某一片型该用哪种构图、该留多少空时。读它是为了把"不好看"换成一条能改的构图判断。

## 1. 先判片型，规则才成立

同一套版式规则不能套所有片。先认这一次属于哪类：

| 片型 | 版式在做什么 | 不适用什么 |
|---|---|---|
| 讲解／信息型 | 每一帧承担一条信息，帧与帧之间要有明显不同的构图 | 连用中心式；一帧只有大字没有结构 |
| 情绪／氛围型 | 构图服务一种感受，允许长时间同一构图 | "每帧换模板"的配额；"主视觉 ≥40%"的密度门槛 |
| 单人访谈／口播 | 人物位基本固定，版式只在字与人物之间调关系 | 多模板轮换；大留白的炫技 |
| 极简停顿／收束 | 有意留空，让上一段落地 | 密度与"层数"要求；补装饰填满 |

判断顺序：先判片型，再挑构图；判不出片型就说明 §1.1 的"目的"字段还没写清，回 `video-plan`。

## 2. 构图模板

七种可用构图（来自 `composition.md`，条件化后使用）：

| 模板 | 用来做 | 最常出现在 |
|---|---|---|
| 中心式 | 一个主元素 + 大量呼吸；概念名、结论、金句 | 开场、收束、单一概念 |
| 三分法 | 锚在三分交点，余下带支撑或负空间 | 机制步骤 + 标签 |
| 左右分屏 | 两件事并置：前后、说法与事实、两个选项 | 对照、纠错 |
| 分层纵深 | 前中后三层，尺度与透明度不同 | 开场钩子、氛围、设想 |
| 非对称（编辑式） | 主内容压向一侧（6:4、7:3），制造张力 | 密集图示 + 说明栏 |
| 三联 | 三个等区，三条并列 | 三件并列的事 |
| 通栏横带 | 一条横带承载一条线（时间轴、数字线、枚举），约占画面高度两成 | 序列、递进 |

**"至少用 3 种、不重复连用"要条件化**：这条来自讲解型视频的帧序列（`composition.md`），前提是"每一帧都要重新建立一次信息结构"。换成情绪片、单人访谈或极简停顿，它不成立——那里的重复构图是节奏，不是偷懒。替代判据：**同一构图连续出现时，观众是否从第二帧开始就能预判下一帧要说什么**；能预判就是该换，不能预判就留着。

## 3. 画面分区

- **安全边距**：关键内容离边缘留出距离；主视觉型与封面需要更多余量。
- **主内容区**：画面中间 65–75% 是眼睛停留的地方，正文不要压边。
- **字幕带**：带字幕的片子，底部约 17% 留空，主内容与关键图形不得越界（`composition.md` 的硬约定）。无字幕时也建议留，理由是相邻两帧的下沿要一致，否则切镜时下边缘会跳。
- **竖屏与方图要重排，不是裁**：竖屏没有横向余量，左右分屏与三联要改上下堆叠、竖向步骤表；方图只容忍两个紧凑元素并置。居中主元素的锚点随画布比例上移（`composition.md` 给的 0.42×画布高，是"带字幕的讲解片"下的经验值，无字幕时可回到几何中心附近）。

安全边距的具体像素（比如 96–150px）是帧执行层的参数，不写进判断；判断层只写"关键内容不压边"。

## 4. 密度：空与满都是判断

- **主视觉占画面 ≥40%**、**≥3 层纵深**：来自讲解型帧的密度门槛（`composition.md`）。换成情绪片不成立——一片雾、一束光、一张脸占满，没有"层"也成立。替代判据：**缩到 320px，这一帧还剩下一块有辨识度的形状吗**；只剩均匀灰底就是空。
- **开场与收束最容易空**：一块底加一行字，读起来像占位。补的方式不是加装饰，是让这一帧本来就该有的东西出现（环境层、上一段的残留、一个能指认的实物）。
- 纯文字帧也要有结构：字本身的大小对比、位置、一条压住版面的基线，都算结构。
- **满也有限度**：每一帧只允许一个主元素与一个次级结构，其余降级（更小、更轻、更靠边）。同等重量的三个东西并排，观众一个都记不住。

## 5. 负空间

留白的作用是分组、突出重点、控制节奏，不是"显得高级"。

- 组内小间隔、组间大间隔；所有间距相等等于没有分组。
- 主元素周围留大空，它才承担得起重量；次要信息压到边上。
- 失败样子：意外重叠；文字贴边；字幕与下方图形打架；所有地方用同一个默认内边距。

## 6. 层级：至少叠两个维度

权重由强到弱：**面积大 › 在动 › 对比高 › 字号大 › 位置**。只把标题放大一号、字重与颜色与正文一样，读起来仍然弱。三个维度叠在一处（大、高对比、在上三分之一），那一处才无可争议是主元素。

## 7. 2D 画布上的纵深

不想上 3D 时，二到三种手法叠用就能读出空间（`composition.md`"depth on a 2D canvas"）：

| 手法 | 效果 |
|---|---|
| 尺度差 | 大=近，小=远 |
| 虚实 | 模糊=后景，清晰=前景 |
| 透明度 | 低=后退，满=主元素 |
| 遮挡 | 前景压住后景的一部分 |
| 投影层次 | 多层投影制造抬起感 |
| 视差速度 | 动得更快=更近 |
| 反向缩放 | 镜头推进时背景反而变大 |

选两三种就够；七种全上会互相抵消。

## 8. 不该出现在画面里的东西

导航条、页脚、Cookie 提示、滚动条、鼠标指针、浏览器边框、点不动的按钮、为填版面而生的抽象几何、无意义的光斑、紫到蓝的"AI 渐变"。**界面模拟只在主题本身是界面时才成立**，而且要明确"这是重建的界面"。

装饰必须能说出它替谁做事：分隔、指向、计数量、标出一个位置。说不出来就删。

## 9. 验收

- **眯眼测试**：模糊之后还能指出第一、第二和空间分组吗。全部等重就是层级坏了，回第 6 节。
- **缩略测试**：缩到 320px 还认得出主元素吗。
- **满度测试**：这一帧能不能直接当海报。
- **边缘测试**：文字、图形、字幕有没有互相压住；下沿与上一帧是否一致。
- 验收看的是画面，不是样式表：样式一致证明不了画面变好（`资产：visual-language.md`）。
