# 视听判断

这份管"观众看到的和听到的"这一层：片子靠什么成立、哪里出了问题、该改哪一层、两条专业意见打架时听谁的。

它**不给风格配方**。同一句"想要高级"，落到画面上至少有四组可以反向走的选择（大留白 vs 密排、低饱和 vs 高对比、衬线 vs 无衬线、细描边 vs 实心），每组都能成立，也都能显得穷。本份教的是判断条件，不是答案。

## 1. 先分清是哪一层的问题

| 用户这么说 | 通常涉及哪几层 | 先做什么 |
|---|---|---|
| "土""廉价""没质感""像模板" | 焦点与层级、色彩关系、材质与光 | 先判焦点，别先调配色 |
| "像放 PPT""太死板""一动不动" | 动源、节奏、剪接 | 先分病因（§4），别先加动效 |
| "看不进去""听不懂""记不住" | 内容与叙事、信息顺序、时长 | 回 §2，先判成立方式 |
| "好拖""太赶""乱" | 信息密度、剪辑节奏、镜长分布 | 先分诊：密度问题不在剪辑层解决 |
| "听不清""太抢""假" | 声音路线、电平与闪避、发音 | 先分是设计问题还是电平问题 |
| "字来不及看""压到脸了" | 屏上文字四旋钮、版式安全区 | 先量，别先改字号 |

**一个症状很少只有一层。** 字幕不好读可能是文案太长、字号太小、被画面遮挡、镜头运动太快、旁白节奏太赶五件事叠在一起。**先找最上游的那一层**：换配色救构图、加动效救结构、缩字号救文案，都是最贵的返工——把下游现象治了，上游原因还在，下一版会用另一种形式回来。

## 2. 内容与叙事：它靠什么成立

**先判成立方式**，它决定第一个决定是什么：靠信息推进（顺序与因果怎么排）、靠人物变化（观众跟谁、变在哪）、靠情绪体验（节奏与留白怎么走）、靠实拍证据（真实性与时间线）、靠形式实验（语言本身就是内容）。判错这一层，后面全是执行优化。

- **先问有没有一句话必须有人说出来。** 没有就先别写旁白——无旁白是合法路线，不是缺省状态。纯视觉叙事（字卡节奏、屏上字推进、视觉隐喻、声音与静默承担情绪）的做法见 `references/visual-storytelling.md`。
- **主线：段落能不能互换。** 把段落在纸上换位置读一遍，换了之后观众察觉不到损失，说明没有主线，只是把概念按同一待遇排了一遍。这时不要硬加"因为…所以…"的假因果。**但并列蒙太奇是合法的**：清单、多案例合辑、风格盘点的段落本来就该可互换，判据换成"每段自己有没有一个落点"。
- **数字分两类。** 会被人去核的（报价、参数量、临床结论、时间点）必须保真；只用来给大小感的，换成日常经验能比的尺度。换掉原值的，把原值留在"必须能核的"清单里。
- **术语后置。** 先用大白话把事讲清，再挂名字；挂上名字后必须再用到一次，否则这个名不该起。
- **接缝不是报幕。** "接下来我们看第二部分"报的是你的播讲顺序，观众不需要知道稿子有几段。上一段末尾留下一个问题、一笔代价或一个缺口；下一段第一句先回指刚完成的东西，再开新题。
- **标题不是摘要。** 摘要服务的是已经在找这条片的人，标题要决定谁会点进来。观众不认识你、片子在同类里被划过时，标题里最该有一个不平整的地方（反常、代价、具体处境）；观众已经在搜你时，直白更好。标题承诺的东西要在观众还能忍的时间里兑现，兑现不了不是风格问题。
- **开场三秒落在具体处境**，不落在自我介绍、不落在"本期我们讲"、不落在背景铺垫。删掉第一句从第二句开始，观众没损失，第一句就是废的。
- **删句判据只有一条**：删掉这句，观众是不是少知道一件事。只说明屏幕上有什么的，删掉，让画面自己演。旁白承担理由、后果、比较、判断；画面承担结构、顺序、数量。

## 3. 视觉：焦点先于一切

**决定顺序：焦点 → 构图 → 疏密 → 空间 → 排版 → 色彩。前一步解决了就停**——"看起来更用心"不是继续往上的理由。

1. **焦点**：把画面缩到 320px 宽（或眯眼看），还认得出一个主元素吗。认不出，后五步都白做。
2. **构图**：主元素占多大、放在哪、视线从哪进、和文字是什么关系（`references/visual-layout.md`）。
3. **疏密**："空"是没有内容，"留白"是内容之间的间隔；区别在边缘有没有东西托住。
4. **空间**：2D 够不够。只有"不转起来就说不清"才往 3D 走，判断与做法见 `video-types` 的三维一节。
5. **排版**：字号、行高、行长、层级，中文断行在这一步一并判。
6. **色彩与细节**：最后才动色值、描边、阴影、颗粒。

**可读性是交付门槛，不是风格问题。** 按真实视口、真实字体、100% 阅读尺寸判断；缩略图只能判构图，不能判字号。

- **字号**：视频正文不小于屏高 4%（1080p 约 40px 字高），再按观看距离核一次。网页正文 16–18px 直接搬进视频等于放弃可读性——那个值来自阅读型网页，只有换成手机竖屏近距离才近似成立。
- **行高**：中文正文 1.7–1.8；多行中文标题 1.3–1.4。汉字撑满字身框，不要照搬英文海报的 1.0–1.1。注意：代码渲染画面里的"行高低于 1.15 会撞行"是**渲染事故线**，判的是有没有叠字，不是阅读舒适度，两个数管两件事。
- **行长**：正文 45–60 个汉字（约 50–75 字符），超了就加行或加宽。
- **中文断行三缺陷**，见到算没做完：不可拆的词被拆开（"不会""38 秒""47 分钟"）、行末只剩一两个字、一个词跨两行。
- **中英混排**：基线对齐、两种字看起来一样重；数字用等宽数字，单位跟着数字不换行。

**"高级感"不是配方。** 它来自一套语言贯彻到底（同一组字重、同一处分隔方式、同一个色相家族），不来自某一组数值。明确拒绝一条公式：**低饱和 ＋ 慢镜头 ≠ 高级**——它是某类品牌片已经用滥的既有习惯，换到讲知识、讲工艺、讲人的片子里，只是让画面变灰。用户说"高级""克制""有质感"时，先翻成可观察的决定（色相数量上限、留白尺度、字重对比、分隔方式），翻不出来就从理由里删掉。

**什么时候值得重定视觉系统**：只看这一处改动会不会波及第二处（第二镜、第二块版式、下一轮交付）。会，才值得重定；不会，就地改那一处。只做一张封面、只改一处、已有品牌规范或用户已认可上一版时，不要重定——会把上一轮验过的对齐、字号与色彩关系一起推翻。

**示意数据要像真的**：整数指标、"张三李四"、"标题／描述"占位、每条都是"2 小时前"，一眼就是模板。改成带零头的指标、分层的时间、长短不一的名字（顺带验长名排版）、具体动作的按钮文案；同一支片里所有示例共用一个虚构场景。

## 4. 运动与时间：这一镜靠什么动

**动源七类**。镜头同时有多种来源或有意静止时，按实际效果描述，便于后续对照。

| 动源 | 什么样 | 怎么判它成立 | 观众读到 |
|---|---|---|---|
| 主体位移 | 人、器物、场景主体在画面里明显移动、变形、进出 | 最大连通块 > 画面 8% | 有东西在"演" |
| 运镜 | 整帧一起平移、推拉、旋转 | 全局位移 > 4px/帧 | 摄影机在动 |
| 切点 | 镜内不动，动感来自换镜 | 帧差出现尖峰 | 节奏推进 |
| 转场 | 两镜之间的过渡效果 | 大面积渐变 + 无平移 | 段落转换 |
| 元素动效 | 画面内的文字、图形、图标、图表、UI 在动 | 中等连通块 2—8% | 信息在展开 |
| 整段特效 | 全画幅渲染运动，主体仍可辨认 | 大面积变化 + 主体轮廓还在 | 氛围与能量 |
| 静止 | 有意停留 | 帧差接近 0 | 让人看清 |

**"画面一直在变"不等于"有东西在动"。** 碎动（散成十几团小区域、最大连通块往往 < 1%、主体纹丝不动）与整段特效（大面积连续变化、主体可辨）观感完全不同。判据：一镜里最大那块变化都不到画面 2% 而主体没动，大概率是碎动——粒子、光点、星空、扫描线本身都不算"这一镜在动"。**但碎动不禁**：它可以是氛围与呼吸；要问的是声明的动源与实测是否一致。声明"主体位移"却只有碎动，是本包要拦的头号问题——机器门禁看到画面在变会判通过，观众看到的是 PPT。

**"像 PPT"有六种病因，改法相反。** 先归因再动手：

| 病因 | 从成片里怎么看出来 | 改法方向 |
|---|---|---|
| 入场即停 | 入场 0.3 秒后到切镜前帧差接近 0，而口播还在讲 | 补 breathe 层，或判定这是有意停留 |
| 每镜同一个动作 | 抽三镜比入场方向、ease、幅度，全都一样 | 分派不同进场方式，不是换更花的效果 |
| 缓动单一 | 慢放看速度剖面一样（全 linear 或全 `power2.out`） | 按进场／离场／位移分三种 |
| 密度均匀 | 相邻重音间隔几乎相等，听感像节拍器 | 删动作，不是加快剩下的 |
| 动的东西不对 | 观众说"晃"而不是"死板" | 停住 |
| 动源与声明不符 | 方案写"主体位移"，成片里主体不动 | 补真正的主体运动，不是加动效 |

归因必须落到"哪一镜、哪一秒、看到什么"。完整判据与逐条修法在 `references/motion-diagnosis.md`。没看成片就只说假设。

**动之前先问三句**：观众这一刻该看哪、当前景别看得清吗（看得清就不动；画面自己在动——人在走、水在流、线在长——就停住）／这一下是过渡还是重音（过渡用缓的，重音才用快的）／上一个镜头动作是什么（别重复同一种运动方向）。

- **缓动是副词。** 同一位移换个 ease 就是另一个意思：`.out` 进场（起步快、收得稳）、`.in` 离场（越走越快被甩掉）、`.inOut` 画面内换位。位移很长（推镜、跨半屏）时方向规则让位给"这段距离看起来是否匀速"；要机械感、逐格感、硬切感时故意不用缓动。
- **速度表示重量**：快（有劲、紧急）／中（大多数内容）／慢（重力、克制）／极慢（情绪、氛围）。这套分级借自产品 UI 的动效规范，**借"快慢有语义"，不搬它的毫秒 token 到镜头上**——产品界面的一次 200ms 与一个推镜是两件事。
- **时长跟距离走**：同一曲线，位移或缩放越大时长必须越长。缩放尤其要按感知速度看：线性改 scale 不等于视觉匀速（可见面积按平方变）。
- **四条路线看需求选，不看审美**：曲线（可 scrub、可逆、跨次渲染一致）／采样折线（复刻参考片节奏）／弹簧（重量与回弹，但**不是时间纯函数**，24/30/60fps 同参数不同形）／分层错帧（速度感、残影，别加在静止物上）。要复刻参考片节奏，用采样折线抽帧测点列，猜一个 ease 名字对不上加速度。

**什么时候不该动**：画面自己在动就停住（实拍里的人、正在描的线、正在倒的水，再叠运镜只会觉得晃）／有意停留可以成立（读字、笑点后的沉默、让人看清一个数）／**纯文字、静态停留是合法片型，不是缺陷**——"每镜必须有具体物体动作"不是门禁。

**效果库不是菜单。** 637 张卡是候选池不是触发器，检索入口是"这一镜观众该看哪、这个动作要说什么"，不是"有没有很酷的效果"。借用时至少改三样：时长（按本镜长度与重音位置重定）、力度（幅度）、配色与方向（跟本片走）。整套搬会把片子变成效果集锦——那是另一种"每镜同一个动作"。见 `references/motion-effect-library.md`。

## 5. 声音：先问它承担什么

同一句"配个音"背后是四种不同的作品；目标不同，路线、分段方式、验收方式都不同。

| 声音在做什么 | 判断信号 | 由此固定下来的事 |
|---|---|---|
| 主叙事 | 漏听就丢信息（纪录片旁白、教程、产品说明） | 人声逐句可懂；音乐在任何时刻不得盖住字 |
| 氛围 | 观众记住的是空间与情绪，不是句子 | 环境层与低频承担主要工作，人声可以很少 |
| 节奏 | 观众跟着动（MV、快闪、开场） | 同步点与音乐时钟优先于句子完整 |
| 无人声／静默 | 用户明确不要人声，或画面自己说得清 | 是合法方案；但要核对丢掉的通道是不是必须传达的信息 |

判不出来时问一句：这段里观众漏听三秒会漏掉什么。漏掉信息 → 主叙事；漏掉情绪 → 氛围；什么都不漏 → 后两类。

**路线由目标定，不是路线决定目标**。真人录音／TTS／已有配音／无人声四条，每条都要能说出贵在哪：真人最真但最贵最慢；TTS 最快最省但韵律最易碎；已有配音免费但不可控；无人声最省但丢掉一条信息通道。

- **分段按语义与表演单元切，不按句切。** 默认"一句一次合成"会把韵律切碎。该并的：同一个意思连着说、被逗号破折号串起来的长句、一口气说完的排比；必须切的：中间要插画面停顿或静默、要换说话人或明显换情绪、工具单次输入到上限。切点放语义边界上，不要就近切。
- **落点只设计一次。** 调用方传"视觉事件的时间"，偏移由音效自己声明（敲击对起点、掠过对峰值、上升音对落点）。卡点准不准就从"每处调用都算对"降成"每类音效设计对一次"。
- **混音三件事分开**：怎么量、量出来是多少（本份）、到多少算能交（`video-release`）。数值达标不等于听感对。两种误差分开报：音频真值误差验分析管线，视觉量化误差验帧率够不够——30 fps 的量化上限约 ±16.7 ms，**不许声称 5 ms 的视觉精度**。
- **"音乐不是铺底，是设计"是一种主张，不是通则。** 氛围片、环境声主导的段落里，音乐恰恰该退成底。要问的是这一段音乐在做什么工作。
- **没听过就写"未听"**，不要用"参数没变"推断"声音没变"。

## 6. 剪辑与接缝：关系决定接法

**转场三层，顺序不能反**：语义（这两场是什么关系：延续／推进／漂移／断裂／时间跳跃）→ 时间（重叠多久、总时长变不变、从哪一帧开始）→ 实现（用什么手段）。语义答错，会做出很漂亮但说错话的接法。

语义先落到一句话：叠化说"这还是同一件事"，硬切说"往下说"或"断了"，慢溶说"跟我漂一会儿"，J cut 是声音先到，L cut 是声音留下。

**没有关系要说时，硬切最省信息**——它不占用观众的解读带宽。**但"必须切"不是通则**：连续段落（一镜到底、连续动作、同一空间里的长段）不切也是决定；卡点片、单个长镜的呼吸都成立。要判的是这一处**该不该发生转换**，不是该不该用转场。

不该用转场的时候：同一场景同一动作被两个机位切开（加叠化像穿帮）／素材自己已经带淡入淡出（先看首末帧）／需要"突然"的地方（惊吓、打断、报错）。

三个工程坑开工前必须先答：**转场吃不吃总时长**（重叠缩短／切点上叠加／首末帧延展，三种语义都真实存在，选一种写进工程备注）／**留空不一定是留白**（"空"被填成首末帧定格，看起来是卡了一下）／**退场动画与转场是两层离开**（已经淡出的一场再加转场，同一场只留一层）。

**"拖"有两种根因，改法相反**：画面在动但信息原地重复 → 信息密度，回 `video-plan` 砍事件并镜；画面基本不动、没有跟动词对应的动作 → 节奏，在这里改编排。抽 10 秒量两个数：信息变化次数、画面变化次数。

**剪辑点三优先级**：信息落地那一刻切（切晚的代价是观众在读空白）／动作完成那一帧切最顺／声音切点放在句尾气口之后、下一句起音之前，不要切在字上。

**切点间隔均匀**：如果不是刻意的，通常说明切点没跟着信息走，观众会感到机械。但**节拍器式的等间隔在某些片型里就是风格**（卡点片、机械感的流程演示），判据是"这个均匀是不是为了那一件事"。

**重定时三阶，前面能用就不许跳**：重排时间轴（这 0.8 秒吃哪一镜的余量）→ 调停顿（掐段末与章前空白，不动一个字）→ 变速（最后手段，会改变瞬态位置，卡点片上卡上的那一下会偏，要写清哪一段变了多少）。发现要改全片预算，回 `video-plan` 报，不自己改。

## 7. 屏上文字：四个旋钮

断句单位／行长／时长与阅读速度／位置与安全区。归不进去的不是字幕问题（文本太长，回文案）。

- **两条约束方向相反，不能合成一条**：最短时长是下限（太短等于没出现），阅读速度是上限（超了读不完）。
- **字符数 ≠ 像素宽度**：按实际字体的像素宽跟可用区比，不数标点。
- **断行是语言问题**：能断在标点就断在标点；数字与单位、否定词、只剩一字的尾行不能拆。
- **平台值与风格值要分开**：每条字幕显示几秒、每行几个字这类数随载体、平台、字号变，是**交付参数**不是专业判断；见 `references/screen-text.md`，用之前先按实际字体与画幅核一次。

## 8. 跨域冲突怎么裁决

- **用户当前目标优先于任何一格规则。** 规则是经验，不是法律；但事实错误、安全、许可不能以"审美选择"豁免。
- **两条专业意见相反时**：先看各自成立的条件（片型、技术条件、版本），再看证据级别，能低成本验证就做个小对比；两者都成立时并列保留，交给用户或小样定。**不按"哪份 Skill 更权威"裁决。**
- **不要为维护某一域的边界放弃综合解决。** 字幕难读可能同时是文案、字号、遮挡、镜头速度、旁白节奏的问题；按域切碎了看，就没人解决它。
- **一次只改一层**，但改之前想清跨层影响：改字号会改变行数与停留时间，改停留时间会改变总时长，改总时长会改变卡点。
- **数值按用途分家**，别让一个数到处跑：阅读型正文（字号/行高/行长）／渲染事故线（叠字、空画面、掉帧）／平台交付值（响度目标、字幕行数）／作者经验起点（"重音动作占三分之一以下"这类，只在原作者那个片型里成立）。写进知识里的每一个数，都要能回答"它在什么条件下成立、失效时什么样"。

## 9. 审美判断怎么写

你可以也应该给出专业审美判断。**判断与"替用户拍板"是两件事**：你可以说"这版在第 7 镜丢掉了呼吸"，用户决定要不要接受这个代价。

一条可信的审美判断包含六件：

1. **判断**：具体到哪一镜、哪一秒、看到什么。
2. **依据**：在真实帧/连续片段/音轨里看到的，能指出来。没看到的不要编。
3. **因果**：为什么会这样读——观众的眼睛先落在哪、听觉被什么占住、信息在哪断了。
4. **可反驳条件**：什么情况下这个判断不成立（换播放尺寸、换个受众、这是刻意的风格）。
5. **置信度**：看得清就说清楚，拿不准就说拿不准，别把两者写成一种语气。
6. **另一条路与代价**：换成什么会怎样，代价是什么（要多花的时间、要丢掉的东西）。

三条纪律：**不把判断伪装成测量**（"显得挤"不是"密度超标 12%"）；**也不因为不能量化就不给判断**（"这个没法量化"通常意味着"我还没找到可观察的差别"）；**只把满不满意、值不值得发、要不要接受这个代价留给用户**。没看过、没听过、没验证的，写明未核——看到几帧不等于看过连续播放，测了响度不等于听过。
