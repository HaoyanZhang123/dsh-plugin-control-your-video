# 动效：这一镜靠什么动

这份管两件事：**定动源**（这一镜的"动"从哪来）与**改单个元素的运动**。读 §1.1 的第 4"动作"、第 5"镜头"与第 11"动源"三个字段，字段定义见 `docs/编写规范.md` §1.1，本份不复述字段表。**转场与整体节奏的执行归 video-edit，这里只管单镜之内。**

## 1. 先判断这次问的是哪一类

| 用户这么说 | 这是哪一类 | 先做什么 |
|---|---|---|
| "这镜怎么动""动源填什么" | 定动源 | 走 §1.5，七类里选 |
| "像放 PPT""太死板""整片一动不动" | 归因 | 走 §2 五种病因，再走 §1.5 判是不是动源错了 |
| "这个动效怎么做""怎么让它有重量""该快还是该慢" | 选动作与缓动 | 走 §3 三问，再 §4 |
| "有没有类似的效果""照这张卡做一个" | 效果库检索 | 走 §6，检索维度在 `references/effect-library.md` |
| "这镜要不要动""能不能不动" | 该不该动 | 走 §5 |
| "两个镜头怎么接""全片节奏拖不拖""剪辑点定在哪" | 不是这份的事 | 转 video-edit |

一次只改一类。归因没做完就先"加点动效"，通常会把病因 1 改造成病因 4。

## 1.5 动源：这一镜的"动"从哪来

七类，每镜必选一个（确有并行的写两个）。字段定义在 `docs/编写规范.md` §1.1 第 11 字段。

| 动源 | 什么样 | 怎么判它成立 | 片子感觉 |
|---|---|---|---|
| `主体位移` | 人、器物、场景主体在画面里明显移动、变形、进出 | 最大连通块 > 画面 8% | 有东西在"演" |
| `运镜` | 整帧一起平移、推拉、旋转 | 全局位移 > 4px/帧 | 摄影机在动 |
| `切点` | 镜内不动，动感来自换镜 | 帧差出现尖峰（硬切） | 节奏推进 |
| `转场` | 两镜之间的过渡效果 | 大面积渐变 + 无平移 | 段落转换 |
| `元素动效` | 画面内的元素在动：文字、图形、图标、图表、UI | 中等连通块 2—8% | 信息在展开 |
| `整段特效` | 全画幅渲染运动，主体仍可辨认 | 大面积变化 + 主体轮廓还在 | 氛围与能量 |
| `静止` | 有意停留 | 帧差接近 0 | 让人看清 |

### 最容易错的一类：满屏碎动

**"画面一直在变"不等于"有东西在动"。** 这两种成片看起来完全不同：

| | 碎动（通常是要改的） | 整段特效（通常是合法的） |
|---|---|---|
| 变化分布 | 散成十几团小区域 | 大面积连续变化 |
| 最大连通块 | 往往 < 画面 1% | 明显更大，或有可辨认主体 |
| 主体 | 主体纹丝不动 | 主体在动，或被特效推着走 |
| 观众读到 | "背景在闪" | "这一段很燃" |

**判据**：一镜里如果最大的那块变化都不到画面 2%，而主体没动，那它大概率是碎动，不是"动了"。**粒子、光点、星空、扫描线本身都不算"这一镜在动"。**

**但碎动不禁。** 一支片里可以有碎动段落（氛围、转场前的呼吸）；要问的是两件事：这一镜声明的动源是不是"整段特效"或"元素动效"？如果声明的是"主体位移"却只有碎动，那就是不一致。

### 片型动源契约

不是每支片都要大块动，但每支片都该明确自己靠什么动：

| 片型 | 默认要求 |
|---|---|
| 爽片／修仙／大片 | **主体位移或运镜 ≥ 30% 镜头**；其余可以是切点、元素动效、整段特效；静止必须写理由 |
| 实拍剪辑 | 切点密度（平均 1.5—2.5 秒一镜）；长镜必须有运镜或主体动 |
| 讲解／演示 | 元素动效为主；整段静止可接受 |
| 情绪／氛围 | 允许大面积静止；但静止段的信息必须在变 |

契约写在方案总览里。**一支爽片如果 70% 的镜头是碎动，方案那一栏就写错了**，不是片子做错了——先改方案。

### 验收：实测动源与声明是否一致

方案写什么，成片就查什么。这一步归 `video-review` 的取证，本份只给判据：

| 声明 | 实测该看到 | 常见不符 |
|---|---|---|
| 主体位移 | 最大连通块 > 8% | 碎动 15 团，最大块 0.6% → "声明的是主体动，做出来是粒子飘" |
| 运镜 | 全局位移 > 4px/帧 | 帧内元素在动但整帧没动 → 其实是元素动效 |
| 切点 | 帧差尖峰 | 没有尖峰，靠内部动 → 是元素动效或主体位移 |
| 整段特效 | 大面积变化 + 主体可辨 | 面积大但主体消失 → 碎动 |
| 静止 | 帧差接近 0 | 有微弱持续变化 → 是元素动效，别写静止 |

**"声明了主体位移，实测只有碎动"是本包要拦的头号问题。** 它比"整片静止"更隐蔽：机械门禁看到画面在变会判通过，观众看到的是 PPT。

## 2. 像 PPT 的归因：先分病因，因为改法相反

| 病因 | 从成片里怎么看出来 | 改法方向 |
|---|---|---|
| 入场即停 | 入场 0.3 秒后到切镜前画面帧差接近 0，而口播还在讲 | 补 breathe 层，或判定这是有意停留 |
| 每镜同一个动作 | 抽三镜比入场方向、ease、幅度，全都一样 | 分派不同进场方式，不是换更花的效果 |
| 缓动单一 | 慢放看每个动作的速度剖面一样（全 linear，或全 `power2.out`） | 按进场／离场／位移分三种 |
| 密度均匀 | 相邻重音间隔的秒数几乎相等，听感像节拍器 | 删动作，不是加快剩下的 |
| 动的东西不对 | 观众说"晃"而不是"死板"：画面自己在动，还叠了推镜或元素运动 | 停住 |
| **动源与声明不符** | 方案写"主体位移"，成片里主体不动、满屏碎点在飘 | 不是加动效，是补真正的主体运动（见 §1.5） |

归因必须落到"哪一镜、哪一秒、看到什么"。完整判据、误判对手、逐条修法在 `references/motion-diagnosis.md`。没看成片就只说假设，不假装看过。

## 3. 动之前先问三句

| 问 | 答案改变什么决定 |
|---|---|
| 观众这一刻该看哪？当前景别看得清吗？ | 看得清就不动；画面自己在动（人在走、水在流、线在长）就停住 |
| 这一下是过渡还是重音？ | 过渡用缓的，重音才用快的。重音动作占镜头数三分之一以下——该作者在解说／科普片型下的实测起点，不是通用配额 |
| 上一个镜头动作是什么？ | 决定这一镜别再重复同一种运动方向；连用几次算多属于整体节奏，归 video-edit |

三句都答不出，说明这一镜还没想清，别先挑效果。

## 4. 缓动、时长与四条路线

- **缓动是副词。** 同一位移换个 ease 就是另一个意思。默认三条：`.out` 用于进场（起步快、收得稳），`.in` 用于离场（越走越快被甩掉），`.inOut` 用于元素在画面内换位置。
- **什么时候上面这条不成立**：位移很长（推镜、跨半屏以上）时，方向规则让位给"这段距离看起来是否匀速"；要机械感、逐格感、硬切感时故意不用缓动；回弹与拖尾不归 ease 管，那是弹簧与错帧。
- **速度表示重量。** 快（有劲、紧急）／中（大多数内容）／慢（重力、克制）／极慢（情绪、氛围）是四级语义。分级借自 IBM Carbon，那是**产品 UI 动效**规范，不是视频规范——借"快慢有语义"，不搬它的毫秒 token 到镜头上。
- **时长跟距离走。** 同一曲线，位移或缩放越大时长必须越长，否则观感"太快"。缩放尤其要按感知速度看：线性改 scale 不等于视觉匀速（可见面积按平方变）。
- **四条路线看需求选，不看审美**：曲线（可 scrub、可逆、跨次渲染一致）／采样折线（复刻参考片节奏）／弹簧（重量与回弹，但**不是时间纯函数**，24/30/60fps 同参数不同形）／分层错帧（速度感、残影，别加在静止物上）。
- **要复刻参考片的节奏，用采样折线。** 抽帧测出"第 n 帧在哪"，存成点列原样用；猜一个 ease 名字对不上参考片的加速度。

细节、条件与引擎语义差别（GSAP／CSS／Lottie／Remotion／Manim）见 `references/motion-principles.md`。

## 5. 什么时候不该动（不适用）

- **画面自己在动，就停住。** 实拍录像里的人、正在描的线、正在长的曲线、正在倒的水，叠一层运镜或再叠元素运动，观众只会觉得晃。
- **有意停留可以成立。** 读字、笑点后的沉默、让人看清一个数，停是决定，不是没做完。
- **纯文字、静态停留是合法片型，不是缺陷。** "每镜必须有具体物体动作""标题／淡入／静态一律不合格"已被否掉，不要拿它当门禁。
- **不适用**：这份不回答"两个镜头之间怎么过渡""全片节奏拖不拖""剪辑点定在哪"（video-edit）；不回答字幕排版（video-edit）；不回答配色、版式、层级（video-visual）；不回答画面能不能用代码画出来、出帧管线怎么搭（video-code-visual）；不定义镜头规格字段（video-plan）。

## 6. 效果库不是菜单

637 张卡是候选池，不是触发器。检索的入口是"这一镜观众该看哪、这个动作要说什么"，不是"有没有一个很酷的效果"。借用时至少改三样：时长（按本镜长度与重音位置重定）、力度（幅度百分比）、配色与方向（跟本片走）。整套搬会把片子变成效果集锦——那是另一种"每镜同一个动作"。分类维度、检索路径与"借什么、改什么"见 `references/effect-library.md`。

## 7. 产出格式

动效建议四行，够用就停：

```
改哪：第 3 镜 / 1.2—2.8 秒
现在：入场 0.3 秒后完全静止，到切镜前没再动
改成：保留入场，在 0.8 秒起加一次 1%/秒的极缓推，覆盖到本镜结束
怎么验：正常速度看 0—3 秒一遍，画面有没有"活过来"又不抢口播
```

把改动值交回 `video-plan`，由它改 §1.1 第 4、5 字段；本份不直接改 `plan.md`，不新开动效表。要改第 9 项"目的"回 video-plan；要改镜头之间的接法与整体节奏回 video-edit。

## 8. 三个判断示例

**1. 用户说："这片子看着像放 PPT，是不是动效做少了？"**
→ 你这样判断：先分病因。抽第 2、4、7 镜看，三镜都是 0.3 秒从下方 30px 淡入，然后到切镜前完全不动，帧差接近 0——这是病因 1（入场即停）加病因 2（每镜同一个动作），不是"动效总量不够"。
→ 所以你这样做：不加新入场。第 2 镜（口播在讲日志）只留一个 1%/秒的极缓推；第 4 镜画面里手在动，直接停住；第 7 镜属于有意停留，写清"这里是让人读完那行字"就不动。

**2. 用户说："这个数字跳出来能不能有分量一点？"**
→ 你这样判断：分量＝到达后有回稳，不是更快。要回稳就该走弹簧，但这条片子要交付到 30fps 与 60fps 两个版本——弹簧不是时间纯函数，同参数在两个帧率下形不一样。
→ 所以你这样做：用采样折线：先按 30fps 预览定出到达段与回稳段的点列，再按各帧率重采样；幅度给 5%—20% 的回弹，不给更多。

**3. 用户说："照这张效果卡做个粒子聚合，挺酷的。"**
→ 你这样判断：先问这一镜观众该看哪。这一镜同时有标题入场和粒子聚合，两个都在动，观众会看标题——那粒子白做。
→ 所以你这样做：借这张卡的"散→聚"机制，改三样：标题进场去掉，粒子时长拉长到覆盖整段 breathe 而不是 0.6 秒收掉，粒子配色换成本片色板；不搬卡里的舞台尺寸与默认幅度。

**反例（真实会犯）**：全片每一镜都加 4% 慢推，被当成"统一风格"。
错在哪一步：错在把"统一"当成了动效目标，跳过了 §3 第一问。画面自己在动的镜（实拍有人在走）叠推，观众看到的是晃；每镜同一个动作，观众听到的是节拍器。改法是把推删到只剩"这一处在全景下读不清"的两镜，其余停住——静止是决定，不是没做。
