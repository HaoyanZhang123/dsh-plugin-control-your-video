# 失败归因：按证据分类，挑一个最小有效动作

> 何时读：生成结果不对，且已经排除剪辑、声音与审片环节时。读它是为了把问题归到具体一层，选一个最小动作去验，而不是换个说法连抽十次。

## 先分清证据强度

| 强度 | 拿到的是什么 | 能支持什么结论 |
|---|---|---|
| 文档声明 | 官方文档写了能／不能 | 只能说明“文档这么说” |
| 单次生成 | 一条结果不对 | 只能说明“这一次不对”，不能说明模型不行 |
| 多次复现 | 同条件多次在同一处坏 | 才能归到模型边界或参数 |

一次失败就下“这模型做不了”的结论，是这份表最常见的误用。

下面的八类是**常见假设，不穷举**。不在这八类里的现象，照样按“可检验特征→最小动作”的方式处理，不要硬塞进某一条。

## 八类假设

| 类 | 可检验特征 | 最小有效动作 | 不要做 |
|---|---|---|---|
| 创作规格 | 每次都在同一镜、同一段坏，且客观上做不完（时长装不下动作、主体数超上限、要两个相反运镜） | 回 video-plan 改规格：拆镜、加时长、减主体 | 在提示词里加形容词硬压 |
| 措辞 | 换一句话就明显变好，其他部分没动 | 只改一句，其余原样，做一次 A/B | 一次重写整段，之后说不清哪句起作用 |
| 输入 | 素材本身有问题：带字幕的原片、图上写了字、分辨率过高长出纹理、参考里混进了不想要的元素 | 换素材、裁掉、缩放、去字幕后再试 | 反复改提示词去抵消素材问题 |
| 参数 | 请求被拒或异步报错；比例恒等于原片；时长固定差一个常数 | 对照该型号 locked／unlocked 与必填项，改任务类型或参数 | 用散文要求参数做不到的事（“保持横屏”） |
| 随机性 | 同提示词、同参数，多次结果不同且都在可接受范围 | 固定所有变量重抽 1—2 次，再判是否需要改 | 把随机波动当成 bug 去改写法 |
| 模型边界 | 该能力文档没写，或缺通道（无音频、无多镜头、无真正局部重绘） | 换做法：剪辑、代码出画、换型号 | 无限重抽，或承诺“多试几次就行” |
| 服务失败 | 超时、5xx、任务长时间排队、下载到 0 字节、返回成功但无文件 | 查任务状态，用同一请求重试，保留任务号 | 改提示词——这时提示词根本不是变量 |
| 后期 | 生成文件本身没问题，成片里才坏：转场、压缩、字幕压制、调色 | 回剪辑层（video-craft 的剪辑部分）定位 | 重新生成，白花钱 |

## 动作顺序

从上往下试，能用上面的就不跳到下面：

1. 确认不是服务／参数问题（看返回、看任务状态、看比例与时长是否符合该型号规则）。
2. 固定所有变量重抽 1—2 次，排除随机性。
3. **减复杂度**：固定机位、单一动作、清空背景、减少主体，先让它成立。
4. 只改一句措辞，其余原样，做 A/B。
5. 换输入素材（换参考、去字幕、缩图）。
6. 换做法（剪辑补、代码画、换型号）。
7. 回规格（改镜头设计）。

## 反模式

- **换同义词连抽**：“高级”换“质感”、“电影感”换“大片感”，十次之后仍然说不出问题在哪。
- **一次改五个变量**：好转了也不知道是哪一步对，坏了也不知道是哪一步错。
- **把“加高质量／8K／完美细节”当修复**：这类词不改结构，只改观感滤镜，身份错了、比例锁了它都救不了。
- **降速、降振幅、拉长回稳冒充“平滑”**：把问题藏起来，同时把卡点全部错位。要先判断是抖动、跳帧还是剪辑点太硬。
- **拿“已修复”当结论**：没看到新结果就不算修好；没输入就写“未验证”。

## 一次尝试记一行

```text
第 3 次｜只改了一句：把“缓慢环绕”改为 orbit_right + 停留 1 秒
结果：环绕成立，但结尾仍多转半圈
证据：第 6—8 秒连续抽 3 帧；对比第 2 次
判断：措辞层已解决一半，剩下是时长太短装不下 → 回规格
```
