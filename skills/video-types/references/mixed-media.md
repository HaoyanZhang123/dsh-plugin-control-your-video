# 混合媒体：桥接处的功夫

> 何时读：一支片里用了两种以上来源（代码/三维/实拍/生成/图表/字卡），或用户说"看起来像拼的""每段像不同片"。读它是为了在接缝上不出戏。

多来源本身不是问题。**接缝才是。** 观众不会分别评价"这段三维不错、那段实拍不错"，他们读的是"这是一支片吗"。

## 一、先建一张桥接表

剪之前把每条素材的行填完。空着的格子就是将来出戏的位置。

| 项 | 每条素材记什么 | 不一致时会发生什么 |
|---|---|---|
| 画幅与像素比 | 实际宽高 | 黑边、裁切、变形 |
| 帧率 | 实际值（含 23.976 这类） | 卡点在重采样后漂移 |
| 色彩空间与 gamma | sRGB / Rec.709 / 线性 | 一段发灰一段发青 |
| 黑白位 | 0–255 还是 16–235 | 白不白、黑不黑 |
| 底噪与响度 | 是否有环境声、响度 | 一段静一段吵 |
| 运动速度感 | 这几段"看起来动得多快" | 一段快一段慢，像拼接 |
| 文字层 | 字幕/标题在哪一层渲染 | 字号、锐度、位置不一致 |

## 二、统一顺序（顺序错了会返工）

1. **时空先统一**：帧率与画幅先定，再谈节奏。帧率不同时先统一到交付帧率——否则所有卡点都在重采样后偏。
2. **色彩空间再统一**：把不同来源转进同一个工作空间（通常是 sRGB / Rec.709），再调风格。**不要在混合状态下调色**，那是在给每段分别写一个错误的答案。
3. **响度与底噪**：按交付目标统一（见 `video-craft` 的混音一节）；环境声不连续时补一层底。
4. **运动速度感**：最后看一遍全片，把"这一段明显更快/更慢"的地方记下来，用剪辑或微调速度对齐。**注意**：改速度会改变卡点位置，所以这一步放在卡点确定之后、终版之前。
5. **整体 grade 只在最后一步做一次**，不逐段做。

## 三、一致性的三个支点

风格差异可以成为段落标记，前提是这三样对齐：

1. **机位与光线关系**：三维与实拍混剪时，镜头的俯仰角、焦段感、主光方向要能对上。俯角三维接平视实拍，观众立刻觉得换了空间。
2. **色彩空间**（上面第二步）：不是"看起来差不多"，是数值上同一个空间。
3. **运动速度**：同样的"推近"，实拍是摄影机移动的透视变化，代码是缩放，观感不同。要接得上，就对加速度曲线而不只是对时长。

这三个对齐之后，三维段与实拍段的材质差异反而会被读成"这是设计"，而不是"这是拼的"。

## 四、分层责任要写下来

一镜里由多个组件构成时，把责任写进工程备注：

| 层 | 谁负责 | 常见事故 |
|---|---|---|
| 空间/背景 | 三维或实拍 | 与前景比例不对 |
| 主体 | 三维/实拍/生成 | 材质与光不匹配 |
| 文字与标注 | DOM/后期叠层 | 跟着镜头变形、字号不一致 |
| 粒子与特效 | 独立渲染层 | 与主体深度关系错 |
| 合成与调色 | 最终合成 | 各层色彩空间不同 |

**文字永远单独一层**（原因见 `code-driven.md` 的画法选择）。

## 五、合成点必须可复现

- 合成脚本要能一把重来：一条命令从各层素材到成片。
- 每层的输入用**路径 + 摘要**记录，不靠"上次那个文件"。
- 中间产物留工作目录，命名带镜号与版本；不要覆盖上一版（改完要能对照）。
- 合成完的成片才是交付对象；图片序列、分层工程都不是（见 `video-types` §8）。

## 六、常见露馅与修法

| 现象 | 根因 | 修法 |
|---|---|---|
| 一段发灰、一段通透 | 色彩空间/黑白位不同 | 统一到工作空间再 grade |
| 一切到实拍就"变真了" | 三维的光太平均 | 给三维加光比与微小瑕疵，或把三维段做成刻意的风格差异 |
| 切到三维就"变假了" | 机位与焦段不对 | 按实拍的俯仰角与焦段重设相机 |
| 每段速度感不同 | 运动曲线不同 | 对加速度，不只对时长 |
| 字幕在有的段落发虚 | 文字进了渲染层 | 文字提到 DOM/后期层 |
| 响度忽大忽小 | 各段独立定响度 | 按统一目标做一次响度归一 |
| 卡点在成片里偏了 | 帧率重采样 | 先统一帧率，再定卡点 |

## 七、什么时候不该混

如果两种来源的接缝怎么调都出戏，那不是技术问题，是**这一镜本来就不该混**。判断方法：把这一镜单独看三遍，每次都注意到接缝——观众也会。这时回分镜改设计（拆成两镜、或统一成一种来源），不要继续在合成层加补偿。

**未验证**：本份的桥接清单来自工程实践与资产作者的验收记录，本包没有跑过真实的多来源合成项目；"对加速度而不只是对时长"是可辩护的推理，未做观感对照实验。
