# 片型与方案

这份只定三件事：这条片子先定什么、时间怎么分、每一镜写成什么样。镜头规格的字段定义只有一处，见 `docs/编写规范.md` §1.1；本份不复述字段表，只讲怎么填得好。

**开工前先读作品夹的 `brief.md` 意图摘要**（字段定义见 `docs/编写规范.md` §1.2）。读这四项就够：第 3 项定观众与场合，决定时长上限；第 4、5 项是必须有与一定不能有，直接变成结构约束；第 6 项定素材能用多少；第 8 项是还没定的，本份决定要不要问、问哪一条。第 1 项是用户原话、第 2 项是 AI 的理解，两者冲突时以第 1 项为准，并把冲突说给用户。

没有 `brief.md`，或第 1、2 项空着，**先走 `video-intent`**，不要凭空假设用户想要什么，也不要把"我猜他想要"写进结构。

**要在新片里复用一个旧做法**（同一片型、同一类镜头、同一条工具路线），先看资产库入口 `<工作区>/control-your-video/index.md`；存在才读，一行一条筛出候选，只打开命中的那两三条。没有这个文件就说明库还没建，不要凭空说"以前是这么做的"。没进 `index.md` 的条目按不存在处理。

## 1. 先判断这次该不该出方案

判据只有一条：**这次的决定会不会改变别的镜或别的段**。会，才值得重走一遍；不会，就地改那一行。

| 用户这句话 | 处置 |
|---|---|
| "就这一镜""这句话怎么改" | 不进方案层：执行细节就地改那一行，最多动 §1.1 的对应字段，不重走方案层 |
| "字幕挪一下"、断行位置不对 | 字幕位置与断行归 `video-edit`，本份不动 |
| "方案有了，这镜怎么写" | 只补那一行，结构与时长不动 |
| "给我出个方案""这条片子怎么组织""要压到 30 秒" | 走 §2 全流程 |
| 只要提示词／只要合规／只问这一帧为什么糊 | 转 video-prompting／video-release／video-review |

方案不必四节全出：结构不清就先定结构，时长有争议就先算时长，不为了"完整"把没想清的节填满。

## 2. 决定顺序

1. **先问这条片子靠什么成立**：靠讲清一件事、靠一种感受、靠一串可比较的项、靠一个可信的宣示、靠一个人物的变化、靠真实素材本身，还是两者拼接。这决定先定什么、最容易坏在哪（→ `references/format-and-shape.md`）。不是贴标签，是知道**下一个决定该给谁**。判断依据是 §1.2 的第 1、4、5 项——想要的感受、必须有的、一定不能有的；这三项没读就先别定形态。
2. **结构**：一句话说得清主线吗；段落能不能互换（→ `references/structure.md`）。
3. **时长预算**：从"要讲几件事"推总时长，再分到镜头；§1.2 第 3 项写了平台与场合，先拿它锁上限（→ `references/duration.md`）。**配音或素材实测时长回来后必须回填镜长并复核动画覆盖**（规则见 `docs/编写规范.md` §1.1 写法最后一条）：估算只负责开局，实测负责收口，两边都不对账就会做出"画面放完了声音还没到"的空转镜。
4. **镜头规格**：一行一镜填 §1.1（→ `references/shot-format.md`）。
5. **参考与小样**：用户给了参考片就先拆参考再回来定片型（→ `references/reference-rebuild.md`）；只对会推翻方向的风险做小样（→ `references/sample.md`）。
6. **制作路径与交付**：每镜的"做法"要落到当前真有的工具；落不下去就改做法或改这一镜；确实是缺输入，按换路条件留空并写"待定（等 X）"——不许留空且不说明，也不许为了填满编一个具体物。

换路条件：

- 用户已给参考片或成稿 → 先拆参考／先切段，从第 2 步起走。
- 时长被平台或客户锁死 → 先按时长反推"能讲几件事"，再定结构，不要先写结构再砍。
- 素材没到手 → 只定时长与结构，做法列留空，素材到了再补。

## 3. 产出格式

作品文件夹 `plan.md` 四节，够用就停：

- **一句话**：这条片子讲什么、给谁看。
- **结构**：段落名、每段干什么、大致占比。
- **时长**：总时长、各段秒数、以及"合计对不上时先砍哪一头"。
- **镜头**：§1.1 那张表，一行一镜；字段与示例见 `docs/编写规范.md` §1.1，填得好的细则见 `references/shot-format.md`。

台词在 `script.md`，时间线在剪辑工程，风格不单开一列——镜头规格不是分镜脚本。

## 4. 拿到修改单之后

读 §1.3 的六项，先判"改的是创作设计还是执行"，再判波及面：

| 判断 | 条件 | 处置 |
|---|---|---|
| 保留 | 改的是执行细节（位置、清晰度、对齐），创作设计没被否 | 只动对应字段；被认可的镜、段落、时长不动 |
| 局部修补 | 创作设计有一处被否，其余仍成立 | 只重写被否的那几镜；把"哪些必须不变"写进保留项交给下一轮 |
| 重做 | 主线、片型或时长前提被否（"不是这个意思""太长了"） | 回 §2 第 1 步重定，不在原表上逐行打补丁 |

三条硬规则：

- **新结果另存**：`plan.md` 升修订号，旧版留档不覆盖。用户说"还是上一版好"时要能拿回来。
- **只改该改的**：修改单第 5 项写的"必须不变"，就是这一轮的验收边界。
- **判不了就写"还没确定"**并说明缺什么才能判，不替用户定方向。

## 判断示例

**一、800 字说明要变成 2 分钟内部发布片**
用户这么说："这是给同行看的内部发布，两分钟以内，想让人觉得这东西不是玩具，是真能干活的。"
你这样判断：不是"帮我把稿子改顺"，是整条方案；片型偏宣导，可信压过激动；时长先反推词量——中文口播约 4 字/秒，2 分钟约 480 字，800 字要砍掉近一半，这一刀必须在定镜头之前砍。
所以你这样做：先出"一句话＋三段结构＋时长表"，说明砍掉的是功能罗列；再把"机柜灯亮起来""那行日志要真实可核"写进前两镜的画面与保留项；不加快切，不用大字金句。

**二、60 秒压到 15 秒**
用户这么说："太长了，压到 15 秒。"
你这样判断：不是等比压缩镜长；15 秒约 60 字口播，只够一件事加一个证据。等比压缩会把每镜压到读不完字、听不清话。
所以你这样做：先砍事件数（留"是什么"和"凭什么信"），重算时长表，再重排镜头；镜头不短于读完它那行屏上字的时间，短了就删字或删镜。

**三、照一条 30 秒广告做**
用户这么说："就照这条的感觉做一条，我们是记账 App。"
你这样判断：用户看中的多半是节奏和"一个人拿着手机"的表演关系，不是它的分镜表；参考的成立条件（实物道具、单一功能、有代言人）在这里只部分成立。
所以你这样做：借"低开→一个人立传→功能爬升→峰值收场"的能量弧和一个主角的完整动作弧，不借字标压印与产品页交棒；先做一段 6—8 秒代表小样，只验"记账这个动作能不能被看见"，验过再铺开。

**反例**：用户说"这版看着像 PPT"。你判断成"每镜缺动作"，于是给 12 镜都加推镜和物体动作。
错在第一步：没分清是信息没推进（结构）、画面没在演（视觉语言）、还是节奏平（剪辑），就把一个诊断套成全片改造。结果是把一支本该有静态停留的片子改成同一种动作风格——静态停留、纯文字、大字对比本身都可能是成片选择，只有"整段没有变化"才是问题。

## 边界

- 只问某模型提示词怎么写、生成结果动作不对 → `video-prompting`。
- 只问这句台词怎么念、口播稿怎么写 → 写法归 `video-script`，念法与路线归 `video-sound`。
- 只问配音怎么念、音乐垫什么 → `video-sound`。时长预算在本份定；声音侧影响由 `video-sound` 反馈回来再由本份重算，本份不替它算混音与表演。
- 只问转场用什么、节奏为什么拖 → `video-edit`。剪辑点与重定时不在这里定。
- 只问这帧糊不糊、字幕有没有压脸 → `video-review` 取证，结论以修改单回本份判范围。
- 只要配色版式封面 → `video-visual`；只问动效为何像 PPT → `video-motion`；只问能不能发 → `video-release`。
- 能力与素材都没确认却要"定每镜用什么做法" → 先只定时长与结构，做法列留空。
- **不适用**：只有一镜要改 → 就地改那一行，不该调用本份；用户只问某一帧糊不糊、这段为什么拖 → 由 `video-review` 取证，结论以修改单回来再判范围。

## 按需参考

- 动手填 §1.1 那张表，或某一列总是写空 → `references/shot-format.md`
- 判断这条片子先定什么、最容易坏在哪 → `references/format-and-shape.md`
- 段落排不出来、章节能否互换说不清、并列清单要不要因果 → `references/structure.md`
- 时长和内容对不上、要压要延 → `references/duration.md`
- 用户给了参考片或说"照这个感觉" → `references/reference-rebuild.md`
- 拿不准要不要先做一段给人看、小样做多长 → `references/sample.md`
