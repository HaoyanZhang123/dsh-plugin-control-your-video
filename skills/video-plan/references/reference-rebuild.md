# 参考重构：拆参考、借什么、不借什么

> 何时读：用户给了参考片、说"照这个感觉"、或问"能不能做成那样"时。读它是为了分清参考里哪一层值得借、哪一层只是它成立的条件，从而不做出一个壳像、内容不成立的东西。

## 先说清看中的是哪一层

"照这个做"至少有五种意思，处置完全不同：

| 用户看中的 | 具体表现 | 该借的 |
|---|---|---|
| 叙事结构 | "它那种开头先抛问题、最后才揭晓的感觉" | 段落顺序、信息释放的节奏 |
| 节奏与时长分配 | "它每一下就停住，很稳" | 停留与推进的比例、镜长分布 |
| 视觉语言 | "它的颜色和字特别干净" | 画法、配色、字体关系、构图习惯 |
| 具体效果 | "那个数字跳出来的方式" | 那一个手法；别扩散到全片 |
| 只在某个桥段 | "我就想要那个人回头的那一下" | 那一段的设计意图 |

判据是**用户的原话落在哪一层**。用户说"感觉"，往往指的是节奏或视觉语言，不是结构；用户说"它讲得清楚"，才是在说结构。分不清就问一句，比做错一版便宜。

## 拆的时候把观察和解释分开

这是最容易走偏的一步：把"我看到的"和"我以为它为什么好"混成一段，后者就会冒充前者进方案。

**观察**只能写能指着帧说的话：

- 构图：前景有没有遮挡物、主体在画面什么位置、留给字的空白在哪。
- 材料：表面质感、边缘细节、反光、景深、光从哪来。
- 时间：什么在变、注意力被带去哪、停住的时候停多久、下一刀切给谁。
- 文字：哪些字是精确的（数字、名称），哪些只是示意。
- 品类：这是当代界面、语义图解、材料特写、纪实页面，还是人的场景；各自出现在哪。

**解释**写"我们认为它为什么成立"：这一段靠的是证据还是情绪？停留是为了让人读字，还是为了压住节奏？解释可以错，但要标出来是解释，别写成事实。

看不到就说看不到：拿不到参考片的画面、只看到截图、只有用户口头描述，都要在方案里写明"依据是什么"。**看截图不等于看过片子**，静帧看不出运镜和节奏。

## 借什么、不借什么

写成三句话，方案里就这么写，别写成长篇分析：

1. **借**：借的是它成立的那件事，说清是哪一层（"借它每段只讲一个证据、讲完停一秒再走"）。
2. **不借**：说清不借哪一层以及为什么（"不借它的大字压屏，因为我们没有一句能压住的话"）。
3. **换成**：在同样的位置，我们用什么达到同样的目的（"同样的收束，我们用手把东西放回抽屉"）。

第三句是关键。只写"借"和"不借"，做出来往往是缺了一块；写清"换成什么"，才算真的重构。

## 保留目的，重做形式

参考里最有价值的往往不是那个形式，是那个形式当年解决的问题。

- 它用一个回头特写交代"他决定了"。你的片子里没有回头这个动作，但同样需要一个"决定"的信号——可能是手停在半空，可能是灯灭。
- 它用大字对比讲清两个数的差距。你的内容没有两个数，但有"之前／之后"，同样可以靠版式对比讲清。
- 它用一段音乐把情绪推上去。你的片子没有音乐预算，就得靠镜头长度和停顿来推。

反过来，**换主体要连带换所有出现的地方**。把参考里的人物换成你的产品，不能只换最显眼的那一处：那个人在片子里可能同时是说话的人、被拍的对象、界面里的头像、字幕的主语。只改一处，剩下的会露馅。

## 什么时候不该照参考做

四种情况，出现任何一种都要明确说"这里不照参考"：

1. **成立条件不同**。参考有一支团队、有演员、有实拍场地、有一年的素材库；你只有一个人和两个工具。它的结构可能是靠那些条件撑起来的——比如它的"稳"来自每镜都有真实材质，你没有材质，照它的节奏就只是慢。
2. **参考是单个成功样本**。一支片好看不等于那套做法是规律。尤其是"某作者在某类片子里这么做"的配方，换片型、换受众就不成立。可以借，但要写成条件（"在这个片型、这个时长下才借"）。
3. **只借了表面**。把奶油色换成石墨色，不会让一个过时的比喻变现代；把转场换成快切，不会让没有推进的结构变紧凑。判断方法：把参考的视觉全部拿走，剩下那套结构还站得住吗？站不住，说明你借的是皮。
4. **用户其实要的是别的东西**。用户指着一支片说"要这种感觉"，真正想要的可能是"别再做得像内部培训"。这时该改的是整条片子的态度，不是复刻那支片的手法。方案里要把这个判断说出来，让用户能反驳。

## 拆完之后

- 把可迁移的判断写进方案（结构、节奏、视觉语言的哪几条），把不可迁移的配方留在参考文件里，标明"谁的、什么片型下的"。
- 如果要验这套重构成不成立，不要直接铺满全片——选代表镜头做小样，见 `sample.md`。
- 参考拆解值得留档：写进资产库的参考条目（字段见 `docs/编写规范.md` §1.4），注明适用条件与失效条件。写不出失效条件，说明这次拆解还没拆到底。
