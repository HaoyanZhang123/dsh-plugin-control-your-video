# 小样：验什么、做多长、什么时候不做

> 何时读：拿不准要不要先做一段给用户看、或决定要做但不知道做多长验什么时。读它是为了只花时间在会推翻方向的风险上，而不是把成片按比例缩小一遍。

## 只对会推翻方向的风险做

判据一句话：**如果这一点猜错了，已经做好的部分要重做吗？**

- 要重做 → 值得做小样。
- 只是改一处 → 不值得，直接改更便宜。

所以小样只针对"方向级"的不确定。典型的方向级不确定：用户说不清要什么但能认出不要什么；这一套画法／版式能不能撑住整片还没被证明；素材与做法能不能真的产出可用的东西。

## 四类风险，验法不同

| 风险 | 要回答的问题 | 小样该长什么样 |
|---|---|---|
| 结构 | 这样排，观众能不能跟下来？ | 用文字或粗版把两三段串起来跑一遍，看有没有"为什么突然说这个" |
| 视觉语言 | 这套画法／版式／色调撑不撑得住整片？ | 挑最有代表性的几镜（最能暴露问题的，不是最好做的），做出真实的"建立—变化—落定" |
| 声音 | 这个路线（真人／合成／无旁白）听起来对不对？节奏合不合？ | 一段完整的话，带真实的停顿与重音，听完再说 |
| 制作可行性 | 这条做法在当前工具下能不能真出？ | 一镜做到能看，重点看它有没有致命的缺陷（人物崩、文字糊、时长锁死） |

结构风险最便宜也最常被跳过：很多人直接做视觉小样，结果视觉验过了、结构还是错的。

## 数量和长度随任务

没有固定套数，也没有固定长度。判断标准是**这个风险能不能在这段长度里显形**：

- 一个风险、一个方向 → 一段就够。
- 需要用户在两三个方向里选 → 每个方向各一段，且**方向要真的不同**（"一个思路是持续跟拍，一个是同一张桌子上摆件"），不能只是换个颜色或换个运镜方向——那样用户选不出来，也没验到什么。
- 长度以"能看出变化"为准，不是成片比例。一段"建立—变化—落定"跑完就够；短的十几秒，长的几十秒，取决于这个变化本身要多久。

**不要为了"稳妥"把开场、中段、结尾各做一段。** 那是把成片缩小编译一遍，验的多半是已经定下来的事，而真正会翻盘的那个点反而没验。同理，也不要固定做"三段"：数量由风险数决定，不由流程规定。

## 小样和成片的关系

- 小样是**覆盖选择**，不是缩小的成片。它证明的是"这个方向能成立"，不是"这条片子做完了"。
- 小样过了，**不等于风格定稿**。它只说明这一个风险被排除了；其余镜仍然要按同一套规格逐镜做。
- 一个漂亮的静帧、一段文字描述、一次"技术通过"，都不能证明动起来的处理成立。要真做出来、真看一遍。
- 小样如果被否，先分清否的是哪一层：画法不对（换视觉语言）、方向不对（换结构）、还是执行不好（同一方向重做）。换错层会白做两轮。
- 小样用的素材与参数要留档，成片沿用时能对得上；小样本身不要覆盖成片目录里的文件。

## 什么时候不该做小样

- **方向已经定了**，剩下的是执行问题 → 直接做，做完再说。
- **只有一个镜头或一处修改** → 没有可推翻的方向，直接改。
- **用户已经锁定素材与做法**，且没有可争议的点 → 做了也只是走流程。
- **做小样的成本高于直接返工** → 比如这一镜本来就要重做，先做小样等于做两遍。
- **问题是能直接看出来的** → 时长超了、字幕压脸、字读不清，这些不需要小样，需要修改。

## 展示的时机

小样做完就主动给用户看，并说清：这一段验的是哪个风险、看的时候该看什么、如果不成立我们换什么。

不要拆成"先看这一段、确认了再看下一段"的逐段审批；也不要在小样还没做出来时就汇报"方案已就绪"。方案完成与小样完成是两个主动展示点，其余自己推进。
