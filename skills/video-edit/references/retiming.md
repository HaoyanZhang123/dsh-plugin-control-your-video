# 重定时：重算时间轴与变速的代价

> 何时读：配音或旁白的实际长度与方案对不上，或改了画面后时间轴要重排，或有人提议"把这段变速塞进去"时。读它是为了在重排、调停顿、变速之间选代价最小的那条，并知道什么时候必须回 video-plan 改预算。

## 先量，不要估

- 拿到实际音频后先量三个数：总长、每句起止、句间停顿。
- 方案里的"约 3 秒"是预算，"实际 3.8 秒"是事实。**两个数都要在手上**，差值才是要处理的东西。只有预算一个数时，任何调整都是猜。
- 没有音频就不算。写"未拿到配音，以下按估算"，不要用估算冒充重算。
- 量法：读波形找 onset、读词级时间戳、或直接读时间线。任一可得即可，但要说清是哪种。

## 谁改什么

| 事 | 归谁 | 不能做什么 |
|---|---|---|
| 全片预算、每镜的初次时长分配 | `video-plan` | 本份不改 `plan.md` 的预算行 |
| 配音的实际长度、这句要不要加停顿、局部重配 | `video-sound` | 本份不选人声路线、不重配音 |
| 实际时间轴的重排、切点、字幕起止 | 本份 | 不借重排去改叙事结构 |
| 删一场、加一场、换顺序 | `video-plan` | 本份不自行砍事件 |

交接只有一句：**plan 定"全片 40 秒、第 1 镜 3 秒"；剪的时候发现旁白比预想长 0.8 秒，差值先在本份消化；消化不了就回 plan 报"预算要调"，不自己改预算。**

## 旁白变长：按这个顺序，前面能消化就不许跳

1. **重排时间轴（首选）。** 这 0.8 秒吃哪一镜的余量？哪几镜本来就有停留余量（读一行字、看完一个变化）可以借？
2. **借相邻镜。** 过渡镜最好借——它不该长；重音镜不要动（它是全片的力道所在）。
3. **调停顿。** 段内小句之间本来就不该停；掐段末与章前的空白。不动一个字。
4. **变速（最后）。** 见下一节。
5. **回 plan。** 前面都不够就报，不硬塞。

为什么是这个顺序：第 1—3 步都**不改声音**，所以不需要重录、不需要重跑合成缓存、不需要重新对齐字幕之外的东西。第 4 步开始改声音的物理形态，代价跳一级。

## 旁白变短

不要靠"每镜拉长 20%"填满——那只会让整片变慢，不会变好。

三种正当用法：多给一个证据、多留一次停留让人消化、把某个转折讲透。

还要警惕另一面：旁白变短常常意味着**内容不够**，那是 `video-plan` 的事件数问题，不是时间轴问题。本份能做的只是把富余时间放回该放的地方。

## 画面改了要重排

- 只改视觉、不动词时，**复用同一次音频与时间戳，不重新配音**（来自一次真实长片的剪辑记录）。这是"重排优先于重做"的最强理由：一旦重配，所有下游时间全变，字幕、卡点、切片全部作废。
- 重排后必须重核两件事：每个切点是否还落在语音的句尾气口之后；每条字幕是否还**包住**它的语音（不是大致对齐，是包住）。
- 先做过一次重排之后，别再用"估算语速"推时间——用已经量到的实际值。

## 调停顿：决定"拖"的那一半

- 段内小句之间不该停。一句一个镜头、每句之间都顿一下，整片会显拖——这是一次真实反馈给出的现象（不是规则，是可观察的后果）。
- 段末与章前才需要停顿：让人消化、换气、给下一段让位。
- 停顿的分布比停顿的总量更要紧：总量一样，均匀分布听起来像节拍器，不等分布才有起伏。
- 调停顿不改字、不改音，是可逆的。这一条让它排在变速前面。

## 变速的代价

**它改变瞬态位置。** 鼓点、辅音起音、关门声、砸下去的撞击都会被等比例挪走。对卡点片（踩音乐、踩重音）是实质风险：卡上的那一下就偏了，而且偏的量随段落长度累积。

按实现分开看（机制来自 Blender 速度控制 strip 与 ffmpeg 滤镜文档）：

| 做法 | 机制 | 代价 |
|---|---|---|
| 拉伸到目标长度 | 按输入段长度自动算倍速；拉一半就是两倍速 | 倍速后**帧会用完**，用完就重复最后一帧——画面冻住。要手动把后一段接在"动作还要继续"的位置 |
| 倍乘 | 在当前速度上乘一个系数，负值倒放 | 必须手动重设段长，不改长度就多出/短缺时间 |
| 逐帧重映射 | 指定某一输出帧对应哪一输入帧，可打关键帧 | 能做到非均匀变速，但每一段都要自己对 |
| 慢放插值 | 相邻帧交叉淡化，减少慢放时的撕帧 | 运动变糊；插值出来的帧不是真实画面 |
| 只改音频速率（时间伸缩） | 只改时长不改音高 | 音节被等比例压缩，快过某个点就听出"赶"；瞬态照样挪。本轮读到的四份材料没有这一项，属工具通识，用前先查当前工具是否支持 |
| 补帧 | 按运动估计补出中间帧 | 有伪影风险，人物与文字上最容易看出来 |

四条判断：

1. 变速是**不可逆**的（对着成片再变回来会掉帧），所以它排最后。
2. 卡点片优先不用变速；非用不可时，先确认卡点是否落在变速段的边界上（边界处位移为 0）。
3. 变速要记录：哪一段、原速、变成多少、为什么。交付时不写，下一轮没人知道这段被动过。
4. 变速会连带改字幕时长与卡点位置，改完必须重核一遍字幕的两条约束。

## 什么时候必须回 plan（不许硬塞）

| 触发 | 为什么不能自己消化 |
|---|---|
| 单镜超出 ±10% 的预算容差，且这一镜没有余量可借 | 容差是 `docs/编写规范.md` §1.1 的校验线，超了要在方案里写原因 |
| 每镜都在容差内，但累计总时长变了 | 总时长是方案的承诺，不是每镜的加总 |
| 要删/加事件、换顺序 | 那是结构，归 `video-plan` |
| 变速是唯一剩下的手段，而这条片卡点 | 要连着音乐与声音侧一起定，主责在 `video-sound` |

报告写一句话加数：

```
第 5 镜 3.0→3.8 秒（+0.8，旁白实测 3.8 秒）；全片 40.0→41.5 秒（+3.75%）
建议：第 9 镜 2.5→1.7 秒消化，或总时长改 42 秒；两处都会动到第 9 镜的停留
```

不说"预算要调"就把片子剪完，等于把方案变成事后描述——下一轮审片拿什么当判据。

## 字幕跟着重排

- 时间轴一改，字幕起止全部重算。字幕要**包住**它的语音，不能只对齐起点。
- 重算后重核两条约束：最短时长（不够就并块或延后消失）、阅读速度（超了就并块或回 `video-script` 改文本）。
- 起点误差可以量（一项实现记录做到约 1 帧），超过一帧量级就重排。

## 验收

- 全片时长 vs 方案时长：差值能不能用"某几镜各变了多少"逐项解释。
- 每个切点：听一遍，有没有切在字上。
- 变速过的段落：重点听瞬态与卡点对不对得上。
- 抽三条字幕量起点误差。
- 若报了"预算要调"：`plan.md` 的预算行是否由 `video-plan` 改过（不是本份改的）。
