# 参考片拆解：先分层，再写借什么

> 何时读：用户丢来一支或几支片子说"就要这样""照着这个做"，而你要判断他看中的是结构、节奏、视觉语言还是某个具体效果时。读它是为了把"像这支片"拆成能执行、也能拒绝的条目。

## 拆之前先确认看清楚的是什么

- 只给了链接、你没实际看过：不许假装看过。先看，或写明"目前只看到前 X 秒/无声音"，再问他看中的片段。
- 只看过片段：拆解结论限定在这段，不要外推到整支的节奏与结构。
- 多支参考片：以用户点名的那支为准，其余当风格佐证；两支结论冲突时，把冲突写进"我的理解"并说明你按哪支走、为什么。

允许问、也只问这一句："你指的是整支，还是里面某一段、某个瞬间？"答案不同，拆的对象就不同：整支拆结构与节奏，一段拆视觉语言，一个瞬间只拆那个效果。

## 四层，按这个顺序看

**1. 叙事结构**——信息按什么顺序给；先给结论还是先给处境；什么被留到后面才揭示；结尾落在哪（人、物、一句话、一个动作）。

判断：这一层决定"要不要借"。结构是可以搬的，而且搬了收益最大、风险最小；但它属于 video-plan 的重构范围，本份只写清"借结构"这一条。

**2. 节奏与时长**——分成几段；每段各干什么；哪里快、哪里停；总时长大概多少；快慢是靠剪辑切的还是靠画面内部变化。

判断：节奏往往是被误认成"风格"的东西。用户说"就要这个感觉"，多数时候是节奏差，不是调色差。

**3. 视觉语言**——光从哪来、色偏往哪边、材质是什么、景别偏近还是偏远、构图满还是空、字出现在哪、字占多大比重。

判断：这一层可以借，但要问"借哪一项"。全借等于换了人家的美术方向，而且通常做不到。

**4. 具体效果**——某个转场、某个字效、某个音效、某段声音处理。

判断：最容易被当成整片风格的一层。单独一个效果可以写进"必须有的"，但它不构成方向。

## 每一层看什么

| 层 | 具体观察点 | 容易看漏的 |
|---|---|---|
| 叙事结构 | 第一个信息是什么；哪个信息被扣住；转折在第几段；结尾停在人还是事 | 字幕承担了叙事（去掉字就看不懂，说明结构其实很弱） |
| 节奏与时长 | 段落数、每段各干什么、最长的停留出现在哪、快段是靠切还是靠画面内部运动 | 音乐段落与画面段落是否对齐——不对齐时"节奏感"来自音乐不是剪辑 |
| 视觉语言 | 光源方向、色偏、材质、景别分布、构图密度、字的位置与占比 | 同一片里前后视觉语言是否一致；不一致说明那支片也在拼 |
| 具体效果 | 转场方式、字效、音效落点、声音处理 | 效果出现几次——只出现一次的效果不能当风格 |

## 写法：两栏，各 2—3 条

写进意图摘要的"已有材料"里，固定成这个样子：

```markdown
| 已有材料 | 参考片 A（90 秒产品片）：借结构——先给使用中的手，再给结果；借节奏——中段有一次明显的停顿；不借——快切密度（我们素材不够）、它的品牌色与字体。 |
```

借的条目要求：可检验、能落成动作（"开头只给环境声不给音乐"可以；"要有电影感"不可以）。
不借的条目要求：带原因，三类足够——品牌不能占（logo、专属色、招牌版式）、内容不匹配（它的场景我们没有，或和我们的事实冲突）、成本做不到（需要实拍/演员/许可）。

## 常见拆错

- **把效果当风格。** 看到一支片的字效很帅，就写成"要这种风格"。改法：把那个字效单独列一条，风格另拆。
- **只拆视觉不拆声音。** 参考片的劲儿常常在声音上：什么时候没人声、音乐什么时候进、有没有留一段只有环境声。声音关系要单独看一遍（只看不听，写"声音未评估"）。
- **整支复刻。** 复刻会把别人的品牌语言、别人的观众预期一起搬进来。默认借结构不借皮。
- **因为有素材就必须用。** 参考片里有某个镜头，不等于我们的片子需要它。
- **拆完就往下走。** 拆解结论要落进摘要，否则下次讨论又从头猜。

## 拆解结果要不要入库

拆得好的一条（"这类片子里，先给环境声再进人声更容易让人觉得真"）值得进资产库，但这归 video-library，写入前问用户。本份只产出摘要里的"已有材料"一栏。
