# 通用写法：从镜头规格到模型能接受的输入

> 何时读：还没选定模型，或要在多个模型之间复用同一段提示词时。读它是为了确定写什么、写到什么程度，以及查不到型号资料时怎么降级。

## 骨架：一段提示词的顺序

顺序的作用是让模型先拿到不变量、再拿到变量，改动时不容易牵一发动全身。不是每个模型都吃全部八段，缺哪段要看型号参考。

| 段 | 写什么 | 常见错法 |
|---|---|---|
| 总述 | 一句话：谁、在哪、做什么、什么调性 | 先堆风格形容词，主体最后才出现 |
| 主体 | 可指的外观：年龄感、衣物、材质、显著特征 | 写“很帅”“很高级” |
| 场景 | 地点、时间、天气、前中后景各有什么 | 只写“室内” |
| 动作 | 从什么到什么、几个节拍、在哪一段发生 | 写“动作流畅” |
| 镜头 | 景别与运动，用可读句子 | 直接写参数名或代码名 |
| 光影与色彩 | 光源方向与性质、三到五个颜色锚点 | 写“电影感光线” |
| 声音 | 要不要声音；对白、音效、环境、音乐分开写 | 只写“有声音” |
| 限制 | 只写真实风险项，名词式 | 罗列一堆“不要” |

## 从观感到可改的技术量

用户说“不对”时，先把感受翻译成能动的量，再改提示词。这是本份最常用的一张对照表。

| 用户这么说 | 先怀疑这些量 | 不要先动 |
|---|---|---|
| “像海浪／像假的” | 机位高度、峰谷高差、主体占比、推进速度 | 加“更真实” |
| “太满／喘不过气” | 主体在画幅里的占比、留白、前中后景层次 | 加“简洁” |
| “动作不像人” | 关节顺序、重心、接地、动作是否一次只做一件 | 加“自然” |
| “脸变了／不是这个人” | 参考用途、上传顺序与编号、主体数量、是否该用首帧锁 | 加“高质量”“8K” |
| “切点不准” | 时间戳粒度、这一段内容密度、是否需要交给剪辑 | 反复重抽 |
| “光很平” | 光源方向与性质、明暗比、材质反射 | 调“对比度” |
| “风格不统一” | 风格词是否每段都在、颜色锚点是否固定 | 换模型 |

## 查约束：动笔前必须回答的六问

1. 这个型号支持哪些任务类型（新建／编辑／延长／首尾帧／参考／分镜）？
2. 比例和时长是用户能指定，还是被输入素材锁死？
3. 参考素材的数量、单件时长、总时长、格式上限是多少？
4. 素材怎么编号、怎么在正文里绑定？有没有额外的 role／用途字段？
5. 提示词长度上限是多少？超了会被截断还是报错？
6. 有没有音频通道？负向是独立字段还是写在正文里？

六问答不全时的处理：

- 前三问答不上就**不要承诺能锁什么**，改成“先按这个比例出，出完再裁”。
- 第 4 问答不上就**用上传顺序编号**并在正文逐份绑定，这是最不容易出错的写法。
- 第 5、6 问答不上就把提示词写短、把声音要求写成独立短句，并标注“该型号是否支持未确认”。

## 参考素材的三种写法

| 情况 | 写法 | 代价 |
|---|---|---|
| 素材多、需要精确控制 | 逐份编号＋逐份绑定用途 | 提示词变长，容易互相干扰 |
| 素材本身就很准 | 只指代，不复述细节 | 模型可能改动参考细节 |
| 只用素材的一部分 | 在正文里说清用哪一部分（哪段动作、哪块光影） | 需要用户说得出“哪一部分” |

硬规则：编号必须与上传顺序一致；多主体时用清单逐条列映射，不要靠名字。素材映射写错，后面全部作废。

## 不可变项与唯一真相源

改造、延长、重做时，先写“什么不能变”，再写“改什么”。不可变项要指向能被读到的具体东西，不靠记忆。

```text
不可变：总时长 40 秒 / 1200 帧；分镜区间见 plan.md 的镜头表；全局色板见 visual/palette.md
可改：第 3 镜的动作节奏与镜头运动
```

指向文件或常量的好处：下一次改动、下一个人接手，都能拿同一份东西对齐。只写“保持整体风格不变”，等于没写。

## 负向：只写真实风险

- 写成不想要的**元素名词**，不写“不要 X”“禁止 X”这种指令句。
- 只对确实出现过的风险写；没出现过的问题不用预防性罗列。
- 声音、字幕这类有独立控制维度的，优先用型号自己的写法，而不是塞进正文否定句。
- 不要求每段都成对列“允许／禁止”；只有在一改就容易越界时，才写这一对。

## 交付格式

改造类需求给参数表，不给散文：

```text
任务：编辑（原片 8 秒，横屏）
必须不变：时长、画幅、原声、第 2 镜构图
要改：第 5—7 秒，人物从坐下变为起身
查不到：该型号编辑后时长是否严格一致 → 假设允许 ±0.3 秒漂移
验收：抽 5 帧核对人物身份；听原声是否完整保留
```

## 不把一个型号的公式当通用写法

同一厂商两代模型的规则可能相反；不同厂商对“负向”“声音”“时间戳”的支持程度差异很大。所以：

- 公式只用来检查自己有没有漏段，不用来保证效果。
- 型号特有的写法（编号规则、role、时间戳、音频标记）只看该型号参考。
- 换了模型就重查一遍上面六问，不搬上一支片的提示词直接改。
