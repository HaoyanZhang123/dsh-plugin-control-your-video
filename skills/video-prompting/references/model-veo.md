# Veo：要素齐全的镜头描述与负向写法

> 何时读：已选定 Veo，或用户想要一套“要素齐全”的镜头描述模板、要处理“画面里出现了不想要的东西”时。读它是为了知道哪些要素值得写、哪些写法官方自己标了“不保证支持”。

## 一、11 类要素

主体 → 动作 → 场景／情境 → 机位 → 运镜 → 镜头与光学 → 视觉风格（光线／基调／艺术风格／氛围）→ 时间元素 → 音频 → 电影术语 → 负向。

文档明说：不是每条提示词都要写全，但知道每类管什么，才知道缺的那一类该不该补。

| 要素 | 值得写的具体内容 | 容易写空的地方 |
|---|---|---|
| 主体 | 职业、年龄感、物种品种、材质、随身物 | “一个人”“一个产品” |
| 动作 | 基本动作、互动、情绪表情、细微动作、转变过程 | “自然地动” |
| 场景 | 内外景、时间段、天气、时代、空气里的东西（尘埃、雾、湿地面反光） | “漂亮的房间” |
| 机位 | 平视、仰拍、俯拍、鸟瞰、虫视、荷兰角、特写、大特写、中景、全景、广角定场、过肩、POV | “电影感机位” |
| 运镜 | 固定、横摇、纵摇、推轨、横移、升降、变焦、摇臂、航拍、手持、甩摇、弧形 | “有动感” |
| 镜头光学 | 广角、长焦、浅景深、深景深、光晕、移焦、鱼眼、希区柯克变焦 | “虚化好看” |
| 视觉风格 | 光源性质与方向、色调与情绪、艺术风格（写实／动画／画派）、氛围（色板＋大气效果＋质感） | “高级”“大片感” |
| 时间元素 | 慢动作、快节奏、延时、花开放这类渐变、呼吸式的节奏 | “节奏感强” |
| 音频 | 音效、环境声、对白；建议用独立句子写清“要不要声音” | 只写“有声音” |
| 电影术语 | 匹配剪辑、跳切、定场组接、蒙太奇、分割焦平面 | 堆术语但不说明要什么效果 |
| 负向 | 见下节 | 写“不要 X” |

## 二、重要限定：机位、运镜、光学不是开关

文档在机位与镜头光学两节各有一段“Important”：**部分高级机位与高级镜头非官方支持，可靠性取决于整体提示词与用例**。

文档列了 13 种机位、12 种运镜、8 种光学，这是“可以这么写”，不是“写了就一定有”。据此的判断：

- 用户要一个很刁的机位时，**同时写清画面该看到什么**（主体占多大、背景是什么、从哪个方向看），让机位词只做补充。
- 结果反复不中，先降级成更常见的机位 + 明确构图，不要在同一句里叠三个高级项。

## 三、负向：列名词，不写指令句

文档明确不推荐“no walls”“don't show walls”这类指令式否定，推荐**直接列出不想要的元素名词**（“wall, frame”）。

据此：

- 用名词列表，不用祈使句；中文同理，写“墙壁、画框”，不写“不要出现墙壁”。
- 负向只针对真的出现过的风险；文档的示例也只是给一个“不想要城市背景、人造结构、阴沉氛围”的清单，不是每次必填。
- 时间元素与声音这类容易被否定的东西，写在正向句里更有效（“镜头全程静止”比“不要移动”清楚）。

## 四、声音与对白

- 用独立句子说清要不要音频，别指望模型从画面推断。
- 三类分开写：音效（单个明确的声音）、环境声（场景底噪）、对白（引号内直接写台词，并写谁在说）。
- 对白加一点点语气／口音描述是有效的（文档示例里有“带口音的严肃急迫语气”）；但一句里塞太多表演说明会挤掉画面描述。

## 五、可以照抄的结构（不是公式）

```text
[一句场景/主体总述]。主体：…。动作：…（从…到…）。
场景：…（地点、时间、天气、空气里的东西）。
机位：…。运镜：…。镜头：…。
光线：…；色调：…；风格：…；氛围：…。
音频：音效…；环境声…；对白：「…」。
负向：…、…。
```
