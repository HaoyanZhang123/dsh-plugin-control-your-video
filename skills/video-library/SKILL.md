# 跨作品经验

默认从本次项目提供或授权的资源出发。新项目出现相似问题时，先说明旧经验可能帮助哪里，等用户允许再调用 `cyv` 的 `read_experience`。只查当前问题，避免把上个项目的风格自动当作这次偏好。

作品完成后可以建议沉淀少量复用价值高的内容。说明它来自哪个作品或版本，实际效果如何，哪些条件下成立，什么时候会失效。提议时给出预览或清楚可定位的结果，结合用户对本次作品的评价。一次成功应注明验证范围。

用户选择收录后，用 `cyv save_experience` 将项目文件复制到使用场景对应位置，保留项目独立原件。素材和方法可以同属一个使用场景。目录与条目状态以工具返回为准。报告重名或相似条目时，带着来源让用户选择保留、合并或替换。

区分用户明确表达的长期偏好和当次作品约束。保留项中出现过一种颜色、速度或风格，不代表用户希望以后都照用。

需要判断适用条件、相似条目或证据质量时，可经 `cyv read_reference` 按需读取 `references/entry-quality.md` 与 `references/curation.md` 的相关专业方法。历史例子中的目录格式与自动清理惯例仅用于追溯。
