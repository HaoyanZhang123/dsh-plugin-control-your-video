# 声音

## 1. 先判断声音在作品里承担什么

同一句"配个音"，背后是四种不同的作品；目标不同，选出来的路线、分段方式、验收方式都不同。先回答这一问：

| 声音在做什么 | 判断信号 | 由此固定下来的事 |
|---|---|---|
| 主叙事 | 观众漏听就丢了信息（纪录片旁白、教程、产品说明） | 人声逐句可懂；音乐在自己任何时刻都不得盖住字 |
| 氛围 | 观众记住的是空间与情绪，不是句子 | 环境层与低频承担主要工作，人声可以很少 |
| 节奏 | 观众跟着动（MV、快闪、发布开场） | 同步点与音乐时钟优先于句子完整 |
| 无人声／静默 | 用户明确不要人声，或画面自己说得清 | 是合法方案；但要核对丢掉的这条通道是不是必须传达的信息 |

判不出来时问一句：这段里观众漏听三秒会漏掉什么。漏掉信息 → 主叙事；漏掉情绪 → 氛围；什么都不漏 → 后两类。

## 2. 决定顺序

1. **定目标**（上一节）。目标决定路线，不是路线决定目标。
2. **选人声路线**：真人录音／TTS／已有配音／无人声。四条都要能说出贵在哪：真人最真但最贵最慢；TTS 最快最省但韵律最易碎；已有配音免费但不可控；无人声最省但丢掉一条信息通道。**这条路线只由本份定**；要改词、要判断念不顺，回 `video-script` 改文本，不在本份顺手改。
3. **分段**：按语义与表演单元切，不按句切。默认"一句一次合成"会把韵律切碎。规则只有两条：**该并**的——同一个意思连着说、被逗号破折号串起来的长句、一口气说完的排比；**必须切**的——中间要插画面停顿或静默、要换说话人或明显换情绪、工具单次输入到上限。切点放在语义边界上，不要就近切。
4. **设计音乐、音效与静默**：先写音乐在哪段推、哪段收、哪几处留白，再挑音效落点。音乐不是铺底，是设计。
5. **落点只设计一次**：调用方传"视觉事件的时间"，偏移由音效自己声明（敲击对起点、掠过对峰值、上升音对落点）。这样卡点准不准从"每处调用都算对"降成"每类音效设计对一次"。
6. **混音与验收**：测量口径、目标值、听感是三件事——响度**怎么量、量出来是多少**归本份，**到多少算能交**归 `video-release`；数值达标不等于听感对。两种误差分开报：**音频真值误差**验分析管线，**视觉量化误差**验帧率够不够。30 fps 的量化上限约 ±16.7 ms，**不许声称 5 ms 的视觉精度**。没听过就写"未听"。

换路条件：试听段上韵律垮掉且调参救不回 → 回真人，或改文本结构（文本改动归 video-script）；真人录不到 → 降级 TTS，并把"韵律会更碎、局部重配更难"写成代价说明。

## 3. 产出格式

只给三样，别的不必输出：

- **声音方案**（几行）：声音承担什么／路线与理由／分段方式／音乐与静默的骨架／怎么验。
- **写回 plan 的声音要求**：填镜头规格第 7 字段"声音"那一格的**一句话**（字段定义见 `docs/编写规范.md` §1.1）。只写这一镜的人声／音乐／音效／静默要做什么，不写插件、采样率、dB 数值。不改镜号、画面、动作、做法。
- **声音侧的时长影响**：只报"这句念出来会让第 5 镜多约 0.8 秒"。要不要回去改，由 video-plan 定；不重算全片预算。

## 4. 三个判断示例

**一、"第 5 句太平，但声音别变"**

用户这么说：第 5 句太平了，但声音别变。 → 你这样判断：这不是路线问题，是表演单元问题；整段重配会把语流和身份一起改掉。 → 所以你这样做：钉住同一音色与表达方向，只改这一表演单元的重音落点与停顿位置；重配后把这一句和前后各一句连起来听接缝，只有接缝处节奏差到能被听出来，才升到分段层重切。

**二、"卡点不准，都晚一点点"**

用户这么说：卡点不准，好像每一处都晚一点点。 → 你这样判断：全部同向等量偏移不是节拍分析错，是输出链路的音轨偏移；逐点手改只会把错误压进源数据。 → 所以你这样做：拿成片抽出的音轨与原音做偏移量比对，把结果记成一个单独的常量，全片一次归位；源分析值不动，也不逐点改拍号。

**三、"音乐太抢"**

用户这么说：音乐太抢，人声听不清。 → 你这样判断：先分是设计问题还是电平问题——旁白区间音乐该退却没退属于设计；整片音乐都压在人声上属于电平与闪避。 → 所以你这样做：前者改"音乐哪一段退、退到什么程度"，并写进 plan 的声音格；后者只动音乐总线与闪避参数，人声层不动。

**反例**：用户说"这句重配一下"，就把整段旁白重新合成一遍。错在第 2 步——把"一句的表演问题"当成"整条路线要重来"。结果是语流、气口、电平全变一遍，还得重新核接缝与时长，而且用户要的"声音别变"恰好被破坏了。局部问题只在局部修。

## 5. 边界

- **不改词、不判词**：要改词、要判断念不顺，回 `video-script` 改文本（口径同 §2 第 2 步）；这里只改它怎么被念。
- **不重算时长预算**：归 video-plan，这里只报声音侧影响。
- **不定剪辑点与转场**：归 video-edit。
- **不定画面与镜头**：归 video-plan / video-visual。
- **不管交付合规**：AI 标识、权利与平台清单归 video-release；这里只回答"这条音轨量出来是多少、真峰多少、有没有削波"，能不能交归它判。
- **不做的三件事**：不凭"参数没变"就说声音没变；不用整段重配替代局部修改；没有真实听辨就不写听感结论（可以写"数值达标，未听"）。
- **隐性约束要提前写明**："24 fps 下 1 拍 = 12 帧"这类只在末端才炸的约束，写声音方案时就一并写明，别留到合成时才撞。

**不适用**：纯视觉作品（无音轨、不需要听辨）不必走本份；已经选好成曲、只做换 BGM 与剪辑的平台二次发布，也不必走这里的人声路线判断，直接按 video-edit 的剪辑流程办。
