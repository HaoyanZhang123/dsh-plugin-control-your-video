# 3D 与空间

> 何时读：有人问"这镜要不要上 3D""能不能让它转起来"，或要在画面里安排前后层、空间关系与标注位置时。读它是为了判断这次该留在 2D 还是真的值得上 3D，以及上了之后什么必须答得出来。

## 1. 判据：运动本身是不是解释

只有**运动本身就是解释**时才用 3D（`04-anatomy/references/3d.md` §1）。成立的四类：

| 成立 | 为什么 |
|---|---|
| 转一圈才看得到全貌的物体（转盘、多面件） | 不转就看不到背面与侧面，转动承载信息 |
| 读数随转动变化的刻度、表盘、指标轮 | 数字与指针的关系要靠转动读出 |
| 抓握、拆装、断裂、脱落这类真实动作 | 动作本身是机制的一部分 |
| 装配顺序（爆炸图，按真实拆解方向散开） | 顺序即解释，空间位置就是论证 |

不成立、留在 2D 更便宜也更准：

- 滑一个零件（一条平移就能说清）
- 摆一根针、转一个球（重画一帧比重建一个场景便宜得多）
- 飞入、淡出、旋转装饰、粒子氛围

一句话判据：**把运动去掉，这镜还剩多少信息**。剩得多，3D 就是装饰；剩不下什么，才轮到 3D 上场。

## 2. 上了 3D 之后必须能回答的四个问题

1. **转的时候观众读到哪一条信息**——要能指出具体那一处（滚道接触点、刻度对齐、件与件的相对位置），不是"能看清结构"。
2. **停成静帧还读不读得懂**——退化路径。答不出，说明信息只存在于运动里，任何一帧截图都会失效。
3. **谁付代价**——渲染时间、遮挡排序、资产制作、返工面。运动越复杂，越容易在最后一轮才发现排序错。
4. **出错的第一个征兆是什么**——哪一帧遮挡错、哪条引线穿模、哪段文字跟着转歪、哪个角度露不出的面。

第 1 条答不出，就不上。第 2 条答不出，就准备一版 2D 替代。

## 3. 空间画布的分层

需要一直存在的空间世界时，层要分开管（层拓扑来自 `hyperframes-core/references/spatial-canvas.md`）：

```
固定填充        不参与任何相机变换（底色、氛围）
视口            裁剪边界，永远固定
世界            唯一持有相机变换的那一层
  空间对象      区域、地标、连接线、入口
固定层          HUD、标注、说明、字幕
```

三条纪律：

- **相机变换只属于世界层**。把变换加在别处，文字会被拉斜、字幕会被裁。
- **文字与标注在固定层**，世界层里只留指向它的端点；引线必须落在实物上，不能停在空中（`craft.md` 反例）。
- **远近改变可读性**：远离相机时文字要按距离增减或隐藏，不要缩成一片噪点。

条件化：这套分层是网页／代码实现的空间画布。换成生成模型出图时，层只能靠提示词里的纵深、后景虚化与遮挡近似，做不到真的分层——那时判断要更保守：一次只让一个主体在空间里发生关系。

## 4. 光与材质的一致性

- **一个主光方向**，全片一致；换镜不换光，只换角度。
- **色调阶不超过 4–5 档，其中只有一档是唯一高亮**（`craft.md`"Tones"：lo / mid / hi / lit，lit 只给此刻要看的那一处）。
- **材质给主体，地面与结构留在低对比**；所有东西都上金属与高光，结构就读不出来。
- 结构由厚度、侧面、倒角、浅投影建立，不靠描边。玻璃、发光、线框是最常见的"看起来像 3D 但读不出结构"的做法。
- 平滑曲面的明暗要连续：一条色带突然断在半路，会被看成画坏了（`craft.md` 反复点名的缺陷）。

## 5. 便宜的替代阶梯

能用低一级说清，就不要上高一级：

1. **静帧透视**：一张有透视的图，靠标注指向。
2. **2.5D 分层视差**：前后景不同速度，制造深度（手法见 `references/layout.md` 第 7 节）。
3. **等轴测 2D**：用可精确重画的二维图表现三维关系，转不转都不失真。
4. **真 3D**：只给"必须转"的那一组，其余保持 2D。

每往上一级，制作成本、排序风险与返工面都变大。层级越高越要能回答第 2 节的四个问题。

## 6. 失败模式

- 3D 只为显得高级：观众记住了炫，没记住结构。
- 透视不一致：一条片里换了几次相机原点或视线高度。
- 文字进了 3D：一斜就读不到，字形还会被拉。
- 遮挡排序错：件与件穿插、盖子透过本体、引线穿过实物。
- 动得太多：所有件同时转，观众不知道该看哪一个；一次只让一组动。
- 光与材质不统一：同一物体在两个镜头里像两种材料。
- 用 3D 补内容的空：结构没想清，转起来只会更空。
