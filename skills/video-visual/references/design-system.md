# 设计系统

> 何时读：要定一套配色、字体、间距与层级，或判断"这次该不该重定系统"时。读它是为了分清哪些值是硬门槛、哪些只是某类片子的习惯。

## 1. 什么时候该定，什么时候不该定

判据一条：**会不会有第三处用到同一个值**。

| 情形 | 处置 |
|---|---|
| 多镜、多版式、要复用，或已经出现"这个灰和那个灰差一点" | 定，写成一页纸 |
| 单张封面、单帧、一次修改、已有品牌规范、用户已认可上一版 | 不定，就地取值 |
| 只定这一次真用得到的几种文字、颜色和间距 | 定到够用就停，不铺整套 |

不凭空造一整套设计系统：没有现成标准时，只定义眼下用得到的几档字、几个颜色、一套间距（`resources/research/已确认资产/03-美术图像与提示词/03-oil-ui-references/visual-language.md`）。"先建体系再创作"在短片里几乎总是返工的来源。

## 2. 定顺序：从内容取，不从风格取

1. **色相来源**：品牌资产、实物、内容画面。主视觉就是实物时，主色直接从实物里取。
2. **中性阶**：底色、前景、边框、辅助文字。中性向强调色轻微偏色，比死灰好。
3. **强调**：一处。第二处就不叫强调。
4. **字体角色**：标题／正文／辅助／标签／数据，各一档。
5. **间距基准**：一个数（4 或 8），其余是它的倍数。
6. **禁用项**：三条以内，写清"这条片子不要什么"。

不要从形容词出发。设计方向类材料里的"材质×环境""一个具体场景"这类引擎是网页品牌页的起手式；视频里更省的做法是从这一镜已有的实物、场地、光里取（`resources/research/已确认资产/03-美术图像与提示词/03-oil-ui-references/design-direction.md`"定色彩"的第一来源）。

## 3. 色彩

**四层结构**（来自 OpenDesign `color.md` 的界面体系）：中性 70–90%、强调 5–10%、语义 0–5%、效果（渐变、发光）<1%。

条件化：这个比例是为"界面型画面"定的。换成实拍或电影感画面，中性 70–90% 不成立——天空、皮肤、环境本身就是彩色。替代判断是：**真正承担"强调"的面积只有一处，且每镜最多一个**。

**对比门槛**（WCAG，与片型无关，是硬线）：小字对背景 4.5:1，大字（>18px 或 14px 粗体）3:1。视频还要多过一道字号关：字太小，对比度再高也读不到（见 `SKILL.md` §4）。

**用法**（`resources/research/已确认资产/03-美术图像与提示词/03-oil-ui-references/visual-language.md`"色彩与表面"）：

- 每种颜色有固定用途：文字、背景、动作、选中、状态。品牌色与状态色可以并存。
- 状态不能只靠颜色区分，否则色弱与压缩后的视频都读不出。
- 正反色块交替可以当段落停顿：深底亮字与浅底深字硬边切换，不用渐变过渡。
- 单色／双色体系是完整的色彩身份：一种主色加一种底色，其余由透明度和混色派生。
- 表面层级可以用色温色相偏移区分，不只靠明暗。

**三条默认陷阱**（anti-ai-slop 与 `color.md` 的共同结论）：Tailwind indigo `#6366f1` 一类是最稳的 AI 味；紫→蓝、蓝→青的两段"信任渐变"排第二；没有功能目的、纯装饰的渐变排第三。

## 4. 四组对比：什么时候成立，什么时候显得穷

| 选择 | 成立条件 | 显得穷的样子 |
|---|---|---|
| 大留白 | 内容本身少而准；观看距离近（手机、室内屏）；留白边缘有东西托住 | 空，不是留白：主元素也小，四周没有可读的层次，缩到 320px 只剩一块灰 |
| 密排 | 信息型画面，观众是来扫读比较的；有清晰的分组与对齐 | 挤：所有东西等距、没有分组、没有一条能停住的线，读三秒就放弃 |
| 低饱和 | 纪实、工艺、医疗、专业工具；靠材质与光影建立层次 | 灰：把"没想清楚颜色"伪装成克制，主体与背景同一明度，焦点消失 |
| 高对比 | 强调型画面、封面、需要在小尺寸下仍可读；对比集中在主元素 | 吵：每处都在喊，等于没有主次；或亮部糊成一片白 |
| 衬线 | 叙事、文学、历史、需要"被写下来"的语气；字重偏轻 | 旧：用衬线只是因为"显得高级"，与内容无关；小尺寸下笔画糊掉 |
| grotesk／无衬线 | 说明、技术、城市感、需要中性的语气 | 默认：随便挑一个系统默认字体，没有字重与字距纪律，看起来像没设计 |
| 细描边 | 精密、仪器、图纸感；同一张画面里线宽统一 | 弱：描边和文字一样细，远景就消失；或者该有体积的地方只有线 |
| 实心 | 块面关系明确、需要重量；色块面积承担层级 | 板：一整块实心压住画面，没有呼吸；或每块都实心，层级反而平 |

这八行不是选项菜单，是"同一句需求可以反向走"的证据。判据永远回到内容：这条片子要观众先看见什么、在什么设备上看、看多久。

## 5. 字体与层级

- **角色分档，差别要够大**：编辑／讲解型长内容里，展示字与正文可以差 3–5 倍（`typography-hierarchy-editorial.md`）。换成产品演示或数据页不成立——那里靠"标签 vs 数值"两档就够，拉 5 倍会把版面撑破。
- **可见层级 ≤3 档**（屏上）；超过三档，观众记不住谁比谁重要。
- **字重三档**：读（400）、强调（500–550）、宣告（600+）。700 以上很少必要（`typography.md`）。海报型可以只用 400 与 900 两极，那是另一套逻辑，不要两套混用。
- **两个字体上限**；两个相似的无衬线不要凑一对（`typography.md`"相似字体配对"）。

字号与行高（同一张表里 Latin 与 CJK 不同，汉字撑满字身框）：

| 用途 | Latin 行高 | CJK 行高 | 条件 |
|---|---|---|---|
| 展示／大标题 | 1.0–1.2 | 1.3–1.4 | 多行中文更靠 1.3；区间与失效条件同 `SKILL.md` §4，按真实字形核对（来源 `resources/research/已确认资产/03-美术图像与提示词/03-oil-ui-references/visual-language.md`） |
| 正文 | 1.5–1.6 | 1.7–1.8 | 短句、单行、字幕不走这一栏 |
| 辅助／标签 | 1.5 | 1.5 | 小字加 0.01–0.02em 正字距 |

字距：中文 0（汉字在固定字身格里，负字距只会挤字）；全大写的 Latin 必须 0.06–0.1em 正字距；Latin 展示字 32px 以上 −0.01 到 −0.03em。

行长：正文 45–60 汉字（约 50–75 字符）；长阅读型 60–70 字符。窄体字（condensed）只用于展示标题与短编号，正文用常规宽度。

字体回退：写完必须用真实字体验一遍中文与中英混排。英文样例好看不代表中文排得出来，这是最常见的"看起来没问题"。

## 6. 间距与对齐

- 一套基准，其余是倍数；同一段距离只由一层决定，不要几层样式各加一遍。
- 组内紧、组间松；不对称外边距比四边均分更像有意为之。
- 先用对齐和留白立结构，再考虑容器、卡片、分隔线。
- 线不重复：留白已经分开的地方不再补线；线的粗细对应层级（粗线分版面、细线分栏），全页一致。

## 7. 层级

视觉权重由强到弱：**面积大 › 在动 › 对比高 › 字号大 › 位置（上、左、中心）**。至少叠两个维度才算真的主次；只把标题放大一号，读起来仍然弱（`composition.md`"in-frame visual hierarchy"）。

## 8. 产出格式：一页纸

```
色：角色 / 色值 / 用途（背景、文字、强调、状态）
字：角色 / 字族 / 字重 / 字号 / 行高 / 字距
间距：基准 / 组内 / 组间 / 画面外边距
层级：哪一档做什么，最多三档
禁用：三条以内
```

每条值后面写一句"来自什么、换片型还成不成立"。写不出这一句的值，降级成"这次这么用"，不要写成通则。

## 9. 数值的来源与失效条件

| 值 | 来源 | 成立条件 | 换片型后的替代 |
|---|---|---|---|
| 中性 70–90% | OpenDesign `color.md`（界面） | 界面型、图示型画面 | 实拍片改成"强调只有一处" |
| 强调 ≤2 次/屏 | 同上 | 一屏内可数的强调位 | 视频里按"每镜一个重音"算，按镜不按屏 |
| 展示/正文 3–5 倍 | `typography-hierarchy-editorial.md` | 编辑型长内容 | 产品演示用两档；封面用极端对比 |
| 正文 50–75 字符 | `typography.md` | 拉丁字母 | 中文按 45–60 汉字折算 |
| 三档字重 | `typography.md` | UI 与信息型 | 海报型可用两极 |
| 4.5:1 / 3:1 | WCAG | 与片型无关 | 无替代，硬线 |

## 10. 常见失败

- 没做焦点判断就先配色：换完色，焦点仍然散，可读性还赔掉。
- 把"克制"当结论：克制要落成数值（色相上限、强调面积、字重档数），落不下去就是没想清楚。
- 每个元素各给一个强调色：同一层级的东西必须看起来一样重。
- 用 9–12px 的说明字、低对比细字或压缩行高营造"精致"（`resources/research/已确认资产/03-美术图像与提示词/03-oil-ui-references/visual-language.md` 明令禁止的做法），在视频里等于不可读。
- 只在一套缩略图上验收：缩略图判不了字号、行距与断行。
