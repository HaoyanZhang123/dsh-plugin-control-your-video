# 封面与标题画面

> 何时读：只做封面、缩略图或片头标题画面，或用户说"封面没人点""标题不够抓人"时。读它是为了分清封面该直白还是该给钩子，并把中文字形与比例核到能交付。

## 1. 封面不是缩略海报

三处差别决定了做法：

| | 海报 | 封面 |
|---|---|---|
| 观看尺寸 | 全屏或半屏 | 常常只有 320px 宽 |
| 竞争环境 | 观众已经决定要看 | 一屏里并排十几张，争夺 0.5 秒 |
| 决定什么 | 看什么 | 看不看 |

所以封面的第一判断不是构图好不好，是**一眼能不能读出"这条片子讲什么、凭什么值得看"**。

## 2. 先定钩子，再定画面

四种钩子（来自 `thumbnail-generation.md` 的封面批量实践，适用信息型／知识型长片）：

| 钩子 | 是什么 | 例 |
|---|---|---|
| 冷开场事实 | 最具体、能核、与常识相反的那一条 | "你眼睛里有个黑洞，你却从没见过它" |
| 论点 | 全片要安装的那个重新框定 | "你脑子里没有作者，只有一个旁白" |
| 机制 | 事情怎么运作的那张图 | "你看到的世界，是大脑猜出来的" |
| 反转／镜像 | 结尾把前面重新解释一次 | "你嘲笑 AI 只会猜下一个字，你的大脑也一样" |

挑一个，不要四个都塞。钩子必须能从片子原文里指出来，不能为封面现编一个说法——那会在正文里对不上，观众进来就觉得被骗。

**什么时候可以直白**：题目本身就是卖点（教程标题、产品名、系列号、人名、明确的结论）；观众已经在主动找这条片；片子是工具型、看完就要用的那种。

**什么时候必须给钩子**：信息型长片进推荐流；观众不知道自己需要它；同类题材在同一屏里有五条；片名是抽象概念（"关于效率"这种）。

判据：**把封面标题念给一个没看过片子的人，他能不能说出"这条片子会告诉我什么"**。说不出，就要钩子。

## 3. 文字主导

文字主导型封面里，主标占画面 55–60%（`thumbnail-generation.md` 的深色编辑型模板给的是这个区间）。条件化：这条只对"文字是钩子载体"的封面成立。换成截图型（聊天记录、招聘启事、文件）或人像型封面，文字占比会低得多，钩子由画面里的物件承担；那时不要硬把字放大。

- 主标最多 2 行，可加 1 行更小的副标。
- 主标在 320px 下仍要一眼读完：一般不超过 8–10 个汉字一行（按字体宽度核，不按字数拍）。
- 强调只给一个词（一种颜色或一道着重线），给两处就互相抵消。
- 主体图退到一角或压到文字之下；主体与文字抢面积，等于没钩子。

## 4. 字形必须核验

中文字形是封面最容易出错的地方，且出错后整张不能用。核验项：

- **逐字对照原文**：按"每个字读起来必须正好是这几个字"的标准核，不是"看起来差不多"。
- 形近字（己/已、未/末、拨/拔）、错笔、多字、漏字、繁体混入，都要一个个看。
- 模型或模板生成的封面常见"为了凑笔画加一笔"，放大到 100% 看笔画起收。
- 全尺寸看一遍、320px 再看一遍：小尺寸下糊成一团的字，等于没有这个字。
- 中英混排时英文只留必要的（品牌名、型号），不放假英文当装饰。

## 5. 比例：不裁、不拉

- 按发布平台的原生比例构图，各自重排：16:9、9:16、1:1、4:3 是四张不同的构图，不是一张裁四次。
- 横图可以左右分置主标与主体；竖图要改成上字下物或上物下字；方图只容忍两个紧凑元素并置。
- 出图比例错了就重出，不裁不拉伸——裁会切掉边缘的字，拉会让字形变形（这是最容易被一眼看穿的失败）。
- 安全边距按比例算，不按像素背：竖屏顶部与底部都要留，平台常常在那里叠 UI。

## 6. 标题画面（片头第一帧）

与封面同源，任务不同：封面争点击，标题画面争"留下来"。

- 要交代三件事：这是什么片、给谁、接下来会发生什么的一个暗示。
- 钩子密度可以低于封面：观众已经点进来了，再喊一次反而像广告。
- 字仍然要主导，但可以让画面先动、字后到（动效归 `video-motion`）。
- 与封面同一套字体、色、版式关系；换一套会让观众觉得点错了片子。

## 7. 验收清单

- 320px 下读出主标，且认得出主体是什么。
- 每个字与原文逐字一致；没有多余字、假字、装饰性乱码。
- 主标没有被裁、没有被拉伸、没有压在主体的关键细节上。
- 比例是平台原生比例；安全边距内没有关键内容。
- 关掉颜色只看明暗块面，主标仍然是最亮或最重的那一块。
- 钩子能在片子正文里指到出处。

## 8. 边界

- 封面的生成提示词、模型选择、出图参数 → `video-prompting`。这里只写"要什么关系"，不写模型输入。
- 封面里的字号、行高、字距 → `references/design-system.md`。
- 封面在成片里的出入点、停留时长 → `video-edit`；封面点击后是否对得上内容 → `video-plan` 的结构判断。
- 只判断"这张封面糊不糊、字有没有被裁" → `video-review` 取证，结论以修改单回来。
