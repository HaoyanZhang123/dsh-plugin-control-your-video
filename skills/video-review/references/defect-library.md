# 缺陷库：从现象定位到根因

> 何时读：用户报了一个具体现象（黑尾、字幕压脸、接缝跳、忽大忽小、渲染和预览不一样），要先判它属于哪一层、根因在哪时。读它是为了不在错的那一层上修。

## 一、定位顺序（三层，从便宜到贵）

同一现象在不同层有不同根因，顺序错了会花三倍成本：

1. **技术层**：用 `measure` 拿确定性读数，排除容器、编码、时长、分辨率的问题。这一层几秒钟能跑完。
2. **连续性层**：按 `purpose` 的 `seam`／`motion`／`sync` 三个取值取证据（具体取法见 `observation-checklist.md`）。单帧图像这一层答不了。
3. **设计层**：回到方案里这一镜的"目的"与"保留项"，判断现象是不是设计本身导致的。

判据：**能在技术层排除的，不要在像素上猜；能在一帧里看清的，不要看整段；只能人判的，标"需人判断"，不硬给根因。**

## 二、常见缺陷

| 现象 | 先查什么 | 怎么确认根因 | 容易误判成 |
|---|---|---|---|
| **黑帧/黑尾** | 时长与帧数是否对上；全片首帧、每镜首末帧、最后一帧的亮度 | 若黑出现在镜头边界且前一镜末帧位移/透明度未归零 → 执行问题（离场没归零）；若黑在片尾且长度等于压黑帧数 → 收尾编排问题；若黑落在任意帧且时长不整 → 编码/丢帧，先查技术层 | "艺术留白"；把有意淡入淡出当缺陷 |
| **旁白漂移** | 每句起点与画面事件的偏移，取首/中/尾三点 | 三点偏移量递增 → 时间轴对位问题；三点都偏同一固定值 → 起始偏移；只有个别句偏 → 该句 TTS 或剪辑点问题。词边界缺失时按字数估的字幕会系统性偏后 | 以为配音念错；以为字幕写错 |
| **字幕压脸/穿字幕带** | 该秒原帧 + 人脸局部裁剪；再看该条字幕的动画起点 | 静态重叠 → 安全区没算（执行）；只在滑入前几帧重叠 → 入场位移路线穿过了带（动效）；整段都压 → 版式本身没留位（设计） | 以为字太大；直接缩字号而不动位置 |
| **接缝跳变** | 前镜末 8 帧 + 后镜首 8 帧：主体位置、尺寸、运动方向 | 两边主体位置不连续 → 镜头设计或素材本身不接（回 plan）；位置连续但最后一帧仍未归零 → 执行；只有一帧花屏 → 编码关键帧 | 以为是"节奏问题"；用加转场掩盖接缝 |
| **闪烁** | 该区域连续 8—12 帧的亮度/位置序列；再查源码里同一元素是否渲染了两份 | 亮度周期性来回 → 动效曲线或双层叠渲染；运动中的元素用固定框量会得到假的闪烁 → 跟随 bbox 复测；只在缩放/滤镜后出现 → 渲染管线 | 见闪就删动效；把"排布有规律、按节拍点亮"的点阵当碎屑 |
| **形变** | 连续段逐 2—3 帧看边缘轮廓 | 轮廓随帧漂移、五官或文字融化 → 生成侧问题（回 prompting）或补帧插值；只在编码后出现 → 压缩参数 | 以为是"风格"；把运动模糊当形变 |
| **突然出现/消失** | 接缝前后各 8 帧 | 半个物体凭空出现、整块瞬移 → 生成片段的首末帧不接（回 prompting）；元素到下一镜首帧才满态 → 末拍动画溢出镜头末尾、被切掉（执行）；被卡片底色整块盖住 → 层序 | 判成时序错误；去改时间轴 |
| **节奏拖** | 该段每镜时长 + 画面变化量 + 这一段推进了几个信息点 | 画面在动但信息不前进 → 信息密度（回 plan）；画面完全不动且没有动词动作 → 真实静止（回 edit）；末拍刚落位就切 → 停留不足（不是拖，是"赶"） | 一听"拖"就加快切；把"静止"一律当缺陷 |
| **声画不同步** | 句首与画面对应事件的偏移；再看该事件的入场动画帧数 | 固定偏移 → 轨道起点；逐句递增 → 时长估算/对位；只有某类事件偏 → 该事件被动画延迟（元素在动画中途才到位） | 以为配音念快了 |
| **音量忽大忽小** | 相邻段的集成响度与峰值差 | 段间差明显且与内容无关 → 分段合成后没做统一增益；只有人声段偏小 → BGM 侧链/混音；峰值削波 → 限幅 | 用整体调大掩盖段间差 |
| **渲染后与预览不一致** | 同一帧在预览页与成片里的对照；成片抽帧 vs 工程截图 | 颜色/亮度差 → 色彩空间或编码；字重/字宽变 → 字体回退或缺失；某元素消失 → 渲染层顺序或裁剪容器 | 拿预览页截图当证据；用浏览器截图替代成片抽帧 |
| **元素被盖住/不可见** | 所有应该出现该元素的帧 | 一次都没出现且层序靠前 → 被后画的容器盖住（不是时序）；只在某几帧消失 → 交叉淡入淡出互相抵消 | 判成"没渲染"；去查时间轴 |
| **文字不可读** | 交付尺寸下的原帧；若有整体缩放，把字号乘一遍缩放系数 | 缩放后字号跌破下限 → 改源头字号，不改缩放；字距/行高导致墨迹相撞 → 版式 | 只放大容器不改字号 |
| **事实性错误** | 画面上所有字面量（数字、年份、单位、名称、公式）与事实清单对账；计数动画逐帧看中间值 | 清单里没有的字 → 缺出处；自建算例与同屏其它标注矛盾 → 横向验算；计数中间值清晰可读且像事实 → 要么让它不可读，要么不做计数 | 只查最终帧，不查过程帧 |

## 三、根因判据的三条通则

1. **一处现象，先问"是只有这一处，还是同一根因还有别处"。** 同一根因通常不止一处（一片里同类问题常有 5—8 处）。修之前全片扫一遍，否则修一处、下一版又冒一处。
2. **改一个参数能不能解释全部现象。** 能，才叫根因；只能解释一部分，说明还有第二个原因，别急着下结论。
3. **根因必须能指到一个具体位置或一个具体决定**（某帧的归零、某条字幕的坐标、某个元素的层序、某段增益）。指不到，就还是现象描述。

## 四、哪些"缺陷"其实不是缺陷

| 看着像 | 为什么不一定是 | 什么条件下才真是缺陷 |
|---|---|---|
| 黑场 | 有意淡入淡出、片头片尾压黑、章节卡清场 | 没有意图、吃掉最后一个动作、长度不整 |
| 画面静止 | 没有与台词动词对应的动作时，宁可静着 | 静止超过该片型能忍的时长，且期间没有信息变化 |
| 计数中间值一闪而过 | 快速计数本来就读不到 | 中间值清晰可读且看起来像事实，却没有出处 |
| 转场白闪 | 是事件层的正常手法 | 白闪盖住了该读的字，或频率高到像故障 |
| 背景点阵 | 整齐排布、按节拍点亮的是矩阵，用来表现"多" | 随机散落、尺寸过小、不参与叙事才是碎屑 |
| 慢推 1.0→1.05 | 它是给观众的"常动层"，不是给指标看的 | 每镜都从同一比例重推一次，叠成一推一推 |
| 单帧亮度突变 | 运动中的元素被固定框量会得到假读数 | 跟随 bbox 复测后仍然闪 |
| 两个镜头景别/色温不同 | 有叙事理由的对比 | 同一场景同一时刻无故变色 |
| 同一图元在不同镜里颜色不同 | 语义上确实不同（当前项 vs 已完成项） | 颜色差异没有语义，纯粹因为参数没传 |
| 字号偏小 | 小字是标签层，本来就不该抢主角 | 属于要读的信息，却在交付尺寸下读不清 |

判"不是缺陷"要给理由，不能只说"看着还行"。理由写不出来，就还是缺陷。
