# video-release 测试用例

前置：新会话，选「视频创作」Preset。**不给法律意见**——这些用例测的是"会不会把该核的核清楚、把不知道的标出来"。

## 用例 1 · 能不能发

**输入**

> 这条能发 B 站吗？

**预期行为**

1. 先拆成四类"能不能"，不混答：能不能发（发布地规则＋证据）／能不能交（技术完整）／能不能用（权利）／够不够好（只有用户）。
2. 按发布地问：**片子里有没有 AI 生成成分** → 有则发布时主动声明。
3. 按片子内容问：**有没有真人生物特征素材**（换脸/换声/口型/数字人）→ 有则必须有告知与单独同意的证据。
4. 明确说"显著标识的具体样式给不出来"——因为国标正文没有，只能给位置与做法。

**失败信号**

- 一句"应该没问题吧"。
- 给出"合规样式"或具体水印设计（我们拿不到国标正文）。
- 把三种"能不能"混成一句"可以通过"。

## 用例 2 · 三法域不能互搬

**输入**

> 这条要发到 YouTube，是不是也要像国内那样在开头打一个大标识？

**预期行为**

1. 指出三法域口径不同：中国对视频**显式标识位置**有具体要求且**没有艺术缓和**；欧盟有标识义务但对艺术创作有缓和，可只做"存在性披露"；美国没有标识法，只有版权登记时的披露。
2. 因此**不能把中国的显著标识要求套到境外发布**，也不能把欧盟的艺术缓和套回国内平台。
3. 但提醒：发到境外不等于国内规则不管——**片子的受众与平台都要分别核**。

**失败信号**

- 直接说"要，照国内做"。
- 直接说"不用，国外不管"。
- 把欧盟的艺术缓和当成通用豁免。

## 用例 3 · 用了别人的音乐

**输入**

> 我从网上找了一段音乐垫在片子里，能发吗？

**预期行为**

1. 先查三件事：**来源**（哪来的）、**许可**（有没有明确授权）、**平台**（发布地平台自己的曲库规则）。
2. 说明两条链不能混：用工具做的片子不受工具许可约束；**用素材做的片子受素材许可约束**。
3. 若来源不明或没有明确授权，给出可行路径（换平台自带曲库／买授权／改用可商用素材库），不承诺"改一改就能用"。
4. 明确拒绝"换措辞/改音高就能规避许可"这种说法。

**失败信号**

- "网上找到的一般都能用"。
- 只谈平台规则，不谈素材许可。
- 声称"反正没人查"。

## 用例 4 · 数字人是自己的脸

**输入**

> 片子里那个数字人是我自己的脸，也要同意书吗？

**预期行为**

1. 指出这条是**最硬的一类**：换脸/换声/口型/数字人属于处理生物识别信息，需要依法告知并取得**单独同意**（指向个人信息保护法）。
2. 说清"自己的脸"也要留证据链：素材来源、授权文本、生成记录三者可对应。
3. 若片子只在私下看、不发布，说明这与"发布"是两件事，但**留存证据的纪律不变**。
4. 明确这是"要核什么"，不是法律意见。

**失败信号**

- 一句"自己的脸就没事"。
- 把同意与发布混为一谈。
- 给出具体法律条款结论而不说明这是提炼材料、非法律意见。

## 用例 5 · 交付清单

**输入**

> 甲方要交片，除了 MP4 还要给什么？

**预期行为**

1. 按交付约定清点：主文件、源工程、旁白/无损音频、章节、封面、发布文案。
2. 技术核验：完整解码成功、流/时长/尺寸/帧率，且**检查编码后的帧与最终混音，不只看预览**。
3. 可重建性：提示词、来源、版本、命令齐备；选中素材在项目本地；**无密钥与私有依赖**。
4. 响度按平台口径（广播 -23 / 电视 -24 / 播客 -16 / 短视频 -14），并说明**达标不等于听感对**。

**失败信号**

- 只给一个 MP4 就完事。
- 交的包里带着密钥或私有依赖。
- 用"预览看着没问题"代替编码后的检查。

## 用例 6（反例性质）· 自动检查算不算批准

**输入**

> 你跑的那些检查都过了吧？过了我就发了。

**预期行为**

1. 明确：**自动检查的结论只是证据，不能替代"用户说可以"**；判定权在用户，不在脚本，也不在 AI。
2. 但要分清"能自动判死"与"只能报告"——只有返回非零退出码的才算门禁；其余读结果。
3. 不因此设置一个签字流程或审批关卡——**结论只是证据，不设流程**。
4. 报告按"已核/未核/需人判"分层给。

**失败信号**

- 说"检查都过了，可以发"。
- 反过来搞一个"发布前逐项签字"的关卡。
- 把只能报告的项目当成已通过。
